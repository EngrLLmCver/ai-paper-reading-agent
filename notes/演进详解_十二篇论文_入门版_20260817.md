## 〇、先看全貌：两条主线和一个暗线

深度学习 2012-2017 的演进，就像修一条**从山脚到山顶的路**：

- **主线 1（变深变强）**：路要修更长（网络变深），但越长越难修
- **主线 2（梯度稳定）**：路越长，从山顶往山脚送物资（梯度）越容易丢→要修高速公路、设中转站
- **暗线（1×1 卷积）**：一种叫"1×1 卷积"的工具被反复用在不同地方，像瑞士军刀一样万能

记住这条主线，后面每篇论文都是在解决"路修到某个阶段遇到了新问题"。

## 阶段 0：AlexNet (2012) —— 深度学习的"破冰船"

### 一句话记忆

> **AlexNet = 给传统方法换上了三件新装备：不生锈的弹簧(ReLU) + 随机请假的团队(Dropout) + 电动工具(GPU)**

### 通俗比喻

想象 2012 年前，大家用手动工具（CPU）盖房子（训练网络），而且弹簧（sigmoid 激活函数）会生锈卡住（梯度消失），工人容易偷懒（过拟合）。

AlexNet 做了三件事：
1. **换了不生锈的弹簧**（ReLU）：永远不会卡住，信号畅通
2. **训练时随机让一半工人请假**（Dropout）：逼剩下的工人学会所有人的技能→谁都不能偷懒→防止过拟合
3. **用上了电动工具**（GPU）：速度提升几十倍

### 痛点

| 问题 | 具体表现 |
|------|---------|
| sigmoid 饱和 | $z$ 稍大一点，$\sigma'(z) \to 0$，梯度就传不回去 |
| 过拟合 | 深网络参数多，在训练集上记住答案，考试（测试集）不会做 |
| CPU 太慢 | 60M 参数的网络，CPU 要训几个月 |

### Idea：三个核心改进

#### ① ReLU 替代 sigmoid

$$\text{sigmoid: } f(z) = \frac{1}{1+e^{-z}}, \quad f'(0) = 0.25 \text{（最大导数才 0.25！）}$$

$$\text{ReLU: } f(z) = \max(0, z), \quad f'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$$

**通俗解释**：sigmoid 的导数最大才 0.25，意味着信号每过一层就缩到 1/4。10 层之后：$0.25^{10} \approx 0.000001$——梯度几乎为零。

ReLU 的正区间导数恒为 1，信号不缩放→不会消失。

**比喻**：sigmoid 像一个越来越紧的弹簧门，推到后面就推不动了。ReLU 像一扇普通的门，正方向永远推得动。

#### ② Dropout

训练时，每个神经元有 50% 概率被"置零"（临时关闭）。

**比喻**：一个团队有 100 人，每次训练随机让 50 人请假。剩下的 50 人必须学会原本 100 人的工作→每个人都被逼成了全能选手→不能依赖某个"明星员工"→过拟合减轻。

推理时全部在岗，但每个人权重乘 0.5（补偿训练时的缩放）。

#### ③ GPU 并行

2 块 GTX 580（各 3GB 显存），用 CUDA 并行计算卷积。这是**工程突破**——没有 GPU，AlexNet 根本训练不完。

### 效果

- ImageNet 2012 top-5 错误率 **15.3%**（第二名 26.2%），领先 11 个百分点
- 震惊学术界，开启深度学习时代

### 遗产与遗留

- ReLU 成默认激活，Dropout 成正则化标配
- **遗留**：大卷积核（$11 \times 11$）无规范→VGG 来规范；深层仍训练不稳→Xavier/He 来修

## 阶段 1：VGG (2014) —— "小积木"的胜利

### 一句话记忆

> **VGG = 全部用同一种小积木（3×3）搭，两个小积木叠起来 = 一个大积木的效果，但更省料、更多变化**

### 通俗比喻

AlexNet 像用各种大小的砖头盖房子：$11 \times 11$、$7 \times 7$、$5 \times 5$、$3 \times 3$ 混着用，没有统一标准。

VGG 说：**全用最小的 $3 \times 3$ 砖头！** 两个叠起来，覆盖面积等于一个 $5 \times 5$ 的大砖头，但用的料更少，而且中间多了一次"变形"（ReLU），房子更结实。

### 痛点

AlexNet 的大卷积核：①参数多、计算贵；②没有统一规范。

### Idea：小核级联

**关键观察**：两个 $3 \times 3$ 卷积堆叠（stride=1, pad=1）的感受野 = 一个 $5 \times 5$。

为什么？第一个 $3 \times 3$ 看到中心 3 格，第二个 $3 \times 3$ 在结果上再看 3 格，向两侧各扩展 1 格→总共 5 格。

**参数对比**（设通道数 $C$）：

| | 一个 $5 \times 5$ | 两个 $3 \times 3$ 堆叠 |
|---|---|---|
| 感受野 | $5 \times 5$ | $5 \times 5$（相同） |
| 参数量 | $5 \times 5 \times C \times C = 25C^2$ | $2 \times 3 \times 3 \times C \times C = 18C^2$ |
| 省了 | — | 28% |
| ReLU 次数 | 1 次 | 2 次（更强非线性） |

**比喻**：一个人张开双臂（$5 \times 5$）覆盖 5 格，和两个人手拉手站一起（两个 $3 \times 3$）也覆盖 5 格。但两个人中间有一次"交流"（ReLU），能力更强，而且人数（参数）更少。

### 网络：VGG-16

13 个卷积层 + 3 个全连接层。通道数翻倍策略：64→128→256→512。每经过一次池化，通道翻一倍（保持信息密度）。

### 效果

- ImageNet 2014 top-5 错误率 7.3%（亚军，冠军是 GoogLeNet）
- **$3 \times 3$ 小核成为后续所有网络的标准**

### 遗留

- 138M 参数，绝大多数在全连接层→NIN/GoogLeNet 用 GAP 替代
- 深层仍需预训练初始化→Xavier/He 从理论解决

## 阶段 1：Xavier 初始化 (2010) —— "调音器"的发明

### 一句话记忆

> **Xavier = 在每层之间装一个"调音器"，让信号"音量"不放大不衰减，从头传到尾一样大**

### 通俗比喻

想象你有一串 100 个扩音器连在一起（100 层网络）。如果每个扩音器把音量放大 1.01 倍，到最后就是 $1.01^{100} \approx 2.7$ 倍——还能接受。但如果每个缩小到 0.5 倍，100 层后 $0.5^{100} \approx 0$——完全听不见了。

Xavier 的核心问题就是：**怎么设定每个扩音器的"音量旋钮"（权重方差），让信号从头传到尾不变大不变小？**

### 痛点

随机初始化时 $\text{Var}(W) = \frac{1}{3n}$，导致信号每过一层方差缩到 $\frac{1}{3}$。5 层后：$\left(\frac{1}{3}\right)^5 \approx 0.004$——信号几乎消失。

### Idea：方差守恒

#### 前向传播（信号从前往后）

一层线性变换：$z = W \cdot x$（$n$ 个输入，每个权重方差 $\text{Var}(W)$）

假设 $x$ 各维度独立、$W$ 各元素独立，由方差性质：

$$\text{Var}(z) = n \cdot \text{Var}(W) \cdot \text{Var}(x)$$

**想要信号不变**：$\text{Var}(z) = \text{Var}(x)$，则：

$$n \cdot \text{Var}(W) = 1 \Rightarrow \text{Var}(W) = \frac{1}{n_{\text{in}}}$$

**通俗说**：如果一层有 $n$ 个输入，每个权重方差设成 $\frac{1}{n}$，那经过这一层后信号"音量"不变。

#### 反向传播（梯度从后往前）

同样的逻辑，反向传播要梯度不变：

$$\text{Var}(W) = \frac{1}{n_{\text{out}}}$$

#### 折中

前向要 $\frac{1}{n_{\text{in}}}$，反向要 $\frac{1}{n_{\text{out}}}$，两者一般不相等。Xavier 取**调和平均**：

$$\boxed{\text{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}}}$$

**比喻**：前向说"音量调到 3"，反向说"调到 5"，折中取 4（调和平均）。

#### 关键假设

Xavier 假设 $f'(0) = 1$（激活函数在零点近似线性）：
- **tanh**：$f'(0) = 1$ ✅ 完美
- **sigmoid**：$f'(0) = 0.25$ ❌ 偏小（推导不精确）
- **ReLU**：一半导数为零 ❌ 严重失效

### 效果

- 深度网络可从零训练，不需预训练
- 但对 ReLU 不适用→He 修正

## 阶段 1：He 初始化 (2015) —— "ReLU 砍了一半，音量要翻倍"

### 一句话记忆

> **He = Xavier 发现 ReLU 像一道门只让一半信号过，所以要把"音量旋钮"调大一倍来补偿——$\frac{2}{n}$ 而不是 $\frac{1}{n}$**

### 通俗比喻

Xavier 的调音器假设所有信号都能通过。但 ReLU 是一道"门"：正的信号能过，负的信号被砍掉。

假设信号是零均值对称分布，正负各占一半。经过 ReLU 后，一半的信号没了→信号能量减半。

$$E[a^2] = E[\max(0, z)^2] = \frac{1}{2} E[z^2]$$

**通俗说**：原来满功率 100 的信号，ReLU 一过只剩 50。要补偿，扩音器要多放大 2 倍（把 50 拉回 100）。

### 痛点

Xavier 假设 $f'(0) = 1$（线性），但 ReLU 不是线性的——它砍掉一半信号。

### Idea：修正 1/2 因子

#### 推导

ReLU 的输出 $a = \max(0, z)$。如果 $z$ 是零均值对称分布：

$$E[a^2] = E[z^2 \cdot \mathbb{1}(z > 0)] = \frac{1}{2} E[z^2] = \frac{1}{2} \text{Var}(z)$$

所以：$\text{Var}(a) = \frac{1}{2} \text{Var}(z)$

代入前向方差递推：

$$\text{Var}(a) = \frac{1}{2} \cdot n \cdot \text{Var}(W) \cdot \text{Var}(x)$$

要 $\text{Var}(a) = \text{Var}(x)$：

$$\frac{1}{2} \cdot n \cdot \text{Var}(W) = 1 \Rightarrow \text{Var}(W) = \frac{2}{n}$$

$$\boxed{\text{Var}(W) = \frac{2}{n}}$$

#### 和 Xavier 的对比

当 $n_{\text{in}} = n_{\text{out}} = n$ 时：

| | Xavier | He |
|---|---|---|
| 公式 | $\frac{2}{2n} = \frac{1}{n}$ | $\frac{2}{n}$ |
| 差异 | — | **多了 2 倍** |

差的就是一个 **2 倍**——补偿 ReLU 砍掉的那 $\frac{1}{2}$。

**比喻**：Xavier 的旋钮调到"5"刚好（tanh），但 ReLU 会吃掉一半，所以 He 把旋钮调到"10"（翻倍）。

#### PReLU：让负半轴也有一点信号

$$f(y) = \max(0, y) + a \cdot \min(0, y)$$

ReLU 负半轴完全砍掉（$a=0$），PReLU 让负半轴保留一点斜率（$a$ 可学习，初始 0.25）。像把 ReLU 的"门"改成"半开的门"——负的也放一点过。

### 诚实负面结果：深度退化

He 初始化让 30 层能训练了（Xavier 30 层完全停滞），**但 30 层比 14 层更差**！

| 层数 | Xavier 初始化 | He 初始化 |
|------|-------------|----------|
| 14 层 | 能训练 | 能训练，效果好 |
| 30 层 | **完全停滞** | 能训练，但**比 14 层差** |

这不是过拟合（训练集误差也高），不是梯度消失（He 已解决）——是**优化本身的问题**。这个诚实报告直接催生了 ResNet。

### 效果

- ImageNet top-5 错误率 4.94%，**首次超越人类水平**（5.1%）
- He 初始化成为 ReLU 网络标准（PyTorch 默认 `kaiming_normal_`）

## 阶段 2：NIN (2014) —— "1×1 卷积的诞生"

### 一句话记忆

> **NIN = 传统卷积是"只看一个方面"的单人质检员；NIN 给每个位置配了一个"微型团队"(mlpconv)来综合判断，最后直接投票(GAP)出结果**

### 通俗比喻

传统卷积的操作是：**一个卷积核在图片上滑动，每个位置算一个内积（线性组合）→ 过 ReLU**。这就像一个质检员只做一个检查项目就下结论。

NIN 的想法：**一个检查不够，多查几项！** 在 $3 \times 3$ 卷积之后，再接 1×1 卷积+ReLU，堆叠成微型 MLP。每个像素位置先做空间卷积，再过微型网络做跨通道综合判断。

### 痛点

传统卷积 = 线性滤波器（内积）+ 非线性激活。隐含假设"概念是线性可分的"——但现实概念往往在非线性流形上。

**比喻**：只问一个问题"这个零件合格吗？"（线性），不够。要问多个问题"尺寸对吗？颜色对吗？材质对吗？"（非线性），综合判断。

### Idea：两个核心贡献

#### ① mlpconv 层

$$f_1 = \max(W_1 \cdot x + b_1, 0) \quad \leftarrow \text{3×3 卷积 + ReLU（空间）}$$

$$f_2 = \max(W_2 \cdot f_1 + b_2, 0) \quad \leftarrow \text{1×1 卷积 + ReLU（跨通道）}$$

$$f_3 = \max(W_3 \cdot f_2 + b_3, 0) \quad \leftarrow \text{1×1 卷积 + ReLU（跨通道）}$$

**1×1 卷积是什么？** 在每个像素位置，把 $C_{\text{in}}$ 个通道值做一次线性组合→输出 $C_{\text{out}}$ 个值。这和全连接层完全一样，只不过在每个像素位置都做一次。

**比喻**：1×1 卷积 = "每家每户都发一个微型大脑（MLP），在门口就做完跨通道综合判断，而不是等所有信息汇总到总部再判断"。

#### ② GAP（全局平均池化）

传统做法：最后把特征图展平→全连接层→分类。全连接层参数巨多（VGG 138M 参数中 FC 占 89%）。

NIN 做法：每个特征图直接取全局平均→得到一个数字→每个数字代表一个类别的置信度。

$$\text{GAP 输出}_k = \frac{1}{H \times W}sum_{\text{特征图 } k}$$

**比喻**：不用"总部经理"（FC）做最终决策，让每个"工人"（特征图）直接投票——谁的平均分最高就是哪类。零参数，天然防过拟合。

**为什么 GAP 要配合 mlpconv？** GAP 要求每个特征图代表一个"类别概念"。如果用普通线性卷积，特征图没那么强的语义。mlpconv 的跨通道非线性让特征图更有语义→GAP 才有效。两者缺一不可。

### 效果

- CIFAR-10 错误率 10.41%（maxout 11.68%）
- **1×1 卷积** 和 **GAP** 成为后续所有网络的标准组件

## 阶段 2：GoogLeNet (2014) —— "多镜头照相机 + 通道筛选器"

### 一句话记忆

> **GoogLeNet = 一个相机同时装了放大镜(1×1)、普通镜头(3×3)、广角镜头(5×5)，拍完拼一起；拍之前先让一个"通道筛选器"(1×1降维)把不必要的通道筛掉，省 85% 计算**

### 通俗比喻

VGG 只用一种镜头（$3 \times 3$），但它有个问题：**一个固定大小的镜头看不清不同大小的东西**。小鸟要用放大镜（小核），大象要用广角镜头（大核）。

GoogLeNet 的方案：**同时装上所有镜头**！$1 \times 1$（像素级）、$3 \times 3$（纹理级）、$5 \times 5$（物体级）同时拍照，最后把照片拼在一起，让网络自己学哪种镜头重要。

但 $5 \times 5$ 镜头太贵了！于是拍照前先让"通道筛选器"（1×1 卷积）把 256 个通道筛到 32 个，只带必要的去拍→计算量降 85%。

### 痛点

- VGG 一味堆 $3 \times 3$ 加深→计算量爆炸
- 单尺度感受野→一个小核看不清大目标

### Idea：Inception 多分支 + 1×1 降维

#### ① Inception 模块（多分支并行）

```
          ┌──→ 1×1 conv ──────────────┐
          │                            │
   输入 ──┼──→ 1×1 → 3×3 conv ────────┼──→ 拼接 → 输出
          │                            │
          ├──→ 1×1 → 5×5 conv ────────┤
          │                            │
          └──→ 3×3 pool → 1×1 conv ───┘
```

**为什么有效**：不同大小的卷积核捕捉不同尺度的特征。1×1 看像素级，3×3 看纹理，5×5 看大范围结构。拼在一起，网络自己学各尺度权重。

#### ② 1×1 降维（bottleneck）—— 关键创新

$5 \times 5$ 卷积直接做，输入 256 通道，输出 64 通道：

$$5 \times 5 \times 256 \times 64 = 409{,}600 \text{ 个参数}$$

先用 1×1 把 256 通道降到 32，再做 $5 \times 5$：

$$\underbrace{1 \times 1 \times 256 \times 32}_{8{,}192} + \underbrace{5 \times 5 \times 32 \times 64}_{51{,}200} = 59{,}392 \text{ 个参数}$$

**减少了 85.5%！**

**比喻**：不带筛选器去拍照，每个镜头都要处理 256 个通道的完整信息（贵）。先过筛器只留 32 个最有用的通道→每个镜头只需处理 32 个（便宜）。

#### 1×1 卷积的两种用途

| | NIN | GoogLeNet |
|---|---|---|
| 用途 | 增强非线性 | 降维和升维（丰富特征表达空间） |
| 比喻 | 每户发一个微型大脑 | 拍照前的通道筛选器 |

同一个工具（1×1 卷积），NIN 用来"增强能力"，GoogLeNet 用来"省钱"。

#### ③ 辅助分类器

在中间层（inception 4a、4d 后面）接 2 个分类头，总损失：

$$\text{Loss} = \text{主损失} + 0.3 \times \text{辅助损失}_1 + 0.3 \times \text{辅助损失}_2$$

**比喻**：从山顶到山脚的物资运输，中间设两个中转站。不用一口气从山顶运到山脚，中途可以歇歇。测试时移除中转站，不影响。

### 效果

- ImageNet 2014 双冠（top-5 错误率 6.67%），仅 5M 参数（VGG 的 1/28）
- **bottleneck（1×1 降维）**被 ResNet、DenseNet 直接继承

## 阶段 3：Batch Normalization (2015) —— "每层配一个恒温器"

### 一句话记忆

> **BN = 给每层网络配一个"恒温器"：不管前面参数怎么变，每层输入都被拉回舒适的零均值、单位方差区间；训练时恒温器有随机波动（正则化），推理时锁定固定值（确定性输出）**

### 通俗比喻

想象一个工厂流水线，每道工序（网络层）的输出会给下一道工序当原料。问题是：前一道工序的工人（参数）每天都在调整，导致下一道工序拿到的原料粗细不一（分布漂移）。原料忽粗忽细，工人就得小心翼翼（小学习率），不然就出错。

**ICS（内部协方差偏移）**= 前层参数变→后层输入分布变→工人要不停适应。

BN 的方案：**在每道工序之间装一个"恒温器"**，不管前面怎么变，把原料标准化到固定规格（零均值、单位方差），再让工人自己微调（γ、β）。

### 痛点

ICS 的死锁循环：

$$z \text{ 漂移到饱和区} \to g'(z) \to 0 \to \text{梯度消失} \to W \text{ 不更新} \to z \text{ 无法拉回} \to \text{死锁}$$

### Idea：每层归一化

#### BN 四步

**Step 1-2：算 batch 的均值和方差**

$$\mu_B = \frac{1}{m}\sum_{i=1}^m x_i, \quad \sigma_B^2 = \frac{1}{m}\sum_{i=1}^m (x_i - \mu_B)^2$$

**比喻**：测量当前这批原料的平均粗细和粗细波动。

**Step 3：标准化**

$$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$

**比喻**：把每根原料拉到标准粗细（零均值、单位方差）。$\epsilon$ 是防除零的小常数。

**Step 4：可学习的缩放和平移**

$$y_i = \gamma \hat{x}_i + \beta$$

**为什么需要 Step 4？** 强制标准化把所有原料拉到统一规格，但有些工序可能就需要粗一点或细一点的原料。$\gamma$ 控制粗细（方差），$\beta$ 控制基准线（均值），网络自己学最优配置。

**关键性质**：如果 $\gamma = \sqrt{\sigma_B^2 + \epsilon}$，$\beta = \mu_B$，则 $y = x$（恒等变换）。所以 BN **不降低网络容量**——加了 BN 最坏和没加一样。

#### 为什么放弃了白化？

白化 = 标准化 + 去相关（更彻底）。但：

1. **计算不可行**：协方差矩阵求逆 $O(d^3)$，每层每次前向都算→太贵
2. **梯度不可处理**：$\mu, \Sigma$ 依赖 $W$，反向传播要对 $\Sigma^{-1/2}$ 求导
3. **白化反例**：如果归一化不在计算图里，$b$ 的更新会被归一化抵消→$b$ 无限增长但 loss 不降

**比喻**：白化像"同时控制温度、湿度、气压"——理想但太复杂。BN 只控制温度（方差）和基准点（均值）→简单有效。

#### 训练 vs 推理

| | 训练 | 推理 |
|---|---|---|
| 统计量 | 当前 batch 的 $\mu_B, \sigma_B^2$（每次不同） | 全程移动平均（固定） |
| 效果 | 随机波动→注入噪声→**正则化** | 确定性输出→稳定预测 |

**正则化来源**：不是参数减少（BN 反而增加参数），是 mini-batch 统计量的随机性。每次迭代 batch 组成不同→$\mu_B$ 不同→同一个样本每次得到的归一化结果不同→给隐藏层注入噪声→抑制过拟合。

#### BN 解决 sigmoid 死锁的因果链

$$z \text{ 被 BN 拉回零均值} \to g'(z) \approx 0.25 \to \text{梯度正常回传} \to \text{死锁打破}$$

### 效果

- 训练步数减少 **14 倍**
- 5 倍学习率仍稳定
- BN-x5-Sigmoid 实验：sigmoid + BN 居然能训练→**问题不在 sigmoid，在 ICS**
- **成为几乎所有现代深度网络的标配**

## 阶段 4：ResNet v1 (2016) —— "高速公路"

### 一句话记忆

> **ResNet = 修了一条"高速公路"(短路连接)，信号可以直接跳过中间几层，梯度从山顶直通山脚；不学"考满分"，学"差几分"(残差)**

### 通俗比喻

普通网络（plain network）像一条普通公路：信号每过一个路口（一层）就要"下车检查"（卷积+激活），梯度从山顶往山脚送物资，每过一个路口就丢一点，送到山脚已经所剩无几（梯度消失）。

ResNet 在每几层之间修了一条**高速公路**（短路连接）：信号可以直接跳过中间的路口，从这一层直达后面的层。梯度也可以走高速公路直接回传——即使中间层学不到东西，还有高速公路兜底。

而且，ResNet 不让网络学"考满分"（目标映射 $\mathcal{H}(x)$），而是学"差几分"（残差 $\mathcal{F}(x) = \mathcal{H}(x) - x$）。**学差几分比学满分容易**——如果最优解就是"什么都不变"（恒等映射），网络只需把 $\mathcal{F}$ 的权重推到零就行了。

### 痛点：退化问题

56 层 plain net 的**训练集**误差比 20 层还高——**连训练集都拟合不好**。不是过拟合（过拟合是训练集好测试集差），是优化本身的问题。

何恺明验证：把 20 层后面接 36 层恒等映射，理论上应该不更差，但 plain net 做不到。

### Idea：残差学习 + 短路连接

$$\text{输出} = \mathcal{F}(x, \{W_i\}) + x$$

#### 为什么学残差更容易？

如果最优解接近恒等映射 $x \to x$：
- **学原映射 $\mathcal{H}(x) = x$**：卷积层要精确拟合恒等变换→很难（卷积核天然倾向于做特征提取，不是传声筒）
- **学残差 $\mathcal{F}(x) = 0$**：只需把权重推向零→SGD 自然做到

**比喻**：考试考 100 分（学 $\mathcal{H}$）很难，但考"比 100 分少几分"（学 $\mathcal{F}$）容易。短路连接把"满分基准"$x$ 加回来，网络只需补上"差的那几分"。

#### 梯度视角：加法 vs 乘法

**普通网络**的梯度是连乘（乘法链）：

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \cdot \prod_{i=l}^{L-1} \frac{\partial x_{i+1}}{\partial x_i}$$

每一项是乘法→连乘后要么爆炸要么消失。

**ResNet** 的梯度是加法链：

$$x_{l+1} = x_l + \mathcal{F}(x_l)$$

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_{l+1}} \cdot \left(1 + \frac{\partial \mathcal{F}}{\partial x_l}\right)$$

**那个 "+1" 就是高速公路的贡献**。即使 $\frac{\partial \mathcal{F}}{\partial x_l}$ 很小（中间层学不到东西），梯度还有 1 兜底。

**比喻**：普通公路每个路口都可能丢包裹（梯度消失）。高速公路保证至少有一个"直达通道"——不管中间路口丢多少，至少有一份完整送达。

### 效果

- 训练 **152 层**网络（VGG 深 8 倍），赢 ILSVRC 2015（top-5 错误率 3.57%）
- "加层至少不更差"在残差结构下可达

### 遗留

v1 的高速公路上还有一个"收费站"（ReLU）→ResNet v2 来拆。

## 阶段 4：ResNet v2 (2016) —— "拆掉高速公路的收费站"

### 一句话记忆

> **ResNet v2 = v1 的高速公路上有个收费站(ReLU)，v2 把收费站拆了，变成真正免费的纯高速公路**

### 通俗比喻

ResNet v1 修了高速公路，但高速出口设了一个收费站（ReLU 在 add 之后）：

$$x_{l+1} = \text{ReLU}(x_l + \mathcal{F}(x_l))$$

**收费站的问题**：
- **前向**：信号出了高速还要过收费站，负值被截断→恒等信号失真
- **反向**：收费站（ReLU）是门控的，$x_l + \mathcal{F} < 0$ 时直接关门→"+1"梯度被清零→高速公路断了

ResNet v2 的方案：**把收费站（ReLU）搬到高速入口之前**（pre-activation），让出口变成纯直路。

### 痛点

v1 的 $x_{l+1} = \text{ReLU}(x_l + \mathcal{F}(x_l))$，add 后的 ReLU 是 **post-activation**（后激活）：

- **前向**：下一层拿到的不是 $x_l$，而是 $\text{ReLU}(x_l + \mathcal{F})$——负值被砍，恒等失真
- **反向**：$\frac{\partial}{\partial x_l}\text{ReLU}(x_l + \mathcal{F}) = \mathbf{1}[x_l + \mathcal{F} > 0] \cdot (1 + \frac{\partial \mathcal{F}}{\partial x_l})$

当 $x_l + \mathcal{F} < 0$ 时，ReLU 导数为 0→整个 "+1" 被清零→**高速公路断了**。

**比喻**：收费站有个门卫，看你心情不好（$x_l + \mathcal{F} < 0$）就不让你过。高速公路看着修好了，但门卫随时可能关门。

### Idea：Pre-activation（预激活）

把 BN 和 ReLU 从 add **之后**搬到 conv **之前**：

| | v1（后激活） | v2（预激活） |
|---|---|---|
| 顺序 | Conv→BN→ReLU→Conv→BN→**add→ReLU** | **BN→ReLU→Conv→BN→ReLU→Conv→add** |
| add 之后 | 有 ReLU（收费站） | **什么都没有（纯直路）** |

#### 为什么"干净恒等"重要

当 add 后没有 ReLU（$f = \text{identity}$）时，前向可干净展开：

$$x_L = x_l + \sum_{i=l}^{L-1} \mathcal{F}(x_i, W_i)$$

任意深度 $L$ 和浅层 $l$ 之间，信号是一条**没有收费站的直路**。

v1 做不到，因为 $f = \text{ReLU}$ 把递归变成了嵌套：

$$x_L = f\Big(f\big(\cdots f(x_l + \mathcal{F}_l) + \mathcal{F}_{l+1} \cdots\big) + \mathcal{F}_{L-1}\Big)$$

每层裹一层 $f$（ReLU），不再是干净求和。

### 效果

- 1000 层网络可训练
- **"pre-activation" 成为深层 ResNet 的标准结构**

## 阶段 5：DenseNet (2017) —— "文件夹"替代"覆盖"

### 一句话记忆

> **DenseNet = ResNet 是把新报告"叠"在旧报告上(加法，可能覆盖旧信息)；DenseNet 是把新报告放进新"文件夹"(拼接)，所有历史信息都保留，随时可调用**

### 通俗比喻

ResNet 的 $x + \mathcal{F}(x)$ 像把新报告叠在旧报告上面——两层内容混在一起，如果新报告在上面，旧报告可能被"盖住"看不清。

DenseNet 的 $[x_0, x_1, \dots, x_{l-1}]$ 像把每份报告放进独立文件夹——不互相覆盖，想看哪份就翻哪个文件夹。

### 痛点

ResNet 的 add 有两个隐患：
1. **特征覆盖**：$x + \mathcal{F}(x)$ 相加可能干扰浅层特征
2. **信息压缩**：add 后通道数不变（还是 $C$ 个），历史特征被"揉"进求和结果，无法显式调用

### Idea：Dense Connectivity + 特征复用

$$x_l = H_l([x_0, x_1, \dots, x_{l-1}])$$

每一层的输入 = 前面**所有**层输出的拼接。

#### Growth Rate $k$：每层只补充 k 个新通道

最反直觉的设计：每层只产生 $k=32$ 个新通道。为什么敢这么少？因为前面所有层的特征都拼在输入里了——第 $l$ 层已经能看到 $k_0 + k(l-1)$ 个通道的"集体知识"，自己只需补充 32 个新视角。

**比喻**：ResNet 每层像个"全才"，自己产生 256 个通道（贵）。DenseNet 每层像个"专才"，在已有基础上补充 32 个新特征（便宜）。集体知识通过拼接积累。

#### Bottleneck：压住计算量平方增长

不加 bottleneck：3×3 卷积计算量 $\sim O(k^2 L^2)$（平方增长）。

加 bottleneck（1×1→3×3）后：
- **1×1 卷积**（随层数增长，但便宜）：$\propto (k_0 + kl) \times 4k$
- **3×3 卷积**（**常数，不随层数增长！**）：$\propto 4k \times k \times 9 = 36k^2$

**比喻**：贵的 3×3 卷积被锁在固定预算上，永远不看输入有多少通道。增长的通道被推给便宜的 1×1 处理。

#### 为什么 concat 比 add 更好？

| | ResNet (add) | DenseNet (concat) |
|---|---|---|
| 维度要求 | H、W、C 全一致 | 仅 H、W 一致，C 累加 |
| 历史保留 | 否（被求和稀释） | 是（显式保留） |
| 梯度路径 | 单条加法链 | 每层连到所有后续层（多路径） |

### 效果

- CVPR 2017 Best Paper
- DenseNet-161 用 28.9M 参数达到 ResNet-101（44.5M）同等精度——65% 的参数

## 阶段 5：MobileNet v1 (2017) —— "拆分两个人，各付各的"

### 一句话记忆

> **MobileNet = 标准卷积让"空间"和"通道"互相买单(相乘)；MobileNet 拆成两个人——一个只做空间测绘(depthwise)，一个只做通道混合(pointwise)——各付各的(相加)，计算量降到 1/9**

### 通俗比喻

标准卷积像一个工人同时干两件事：**空间测绘**（用 $3 \times 3$ 核看局部纹理）和**通道混合**（把 $M$ 个通道组合成 $N$ 个）。这两件事的代价是**相乘**的——$N$ 个输出通道每个都要配一整套空间核，太贵。

MobileNet 把这个工人拆成两个：
- **工人 A（depthwise）**：只做空间测绘，每通道独立做，不做通道混合
- **工人 B（pointwise，1×1 卷积）**：只做通道混合，不做空间测绘

两个工人的代价**相加**，而不是相乘→便宜很多。

### 痛点

标准卷积计算量随通道数平方增长，移动端扛不住。

### Idea：深度可分离卷积

#### 计算量推导——乘积变求和（数学核心）

**标准卷积**：

$$\underbrace{D_K^2}_{\text{空间}} \times \underbrace{M \cdot N}_{\text{通道}} \times D_F^2$$

空间和通道**相乘**——每个输出通道都要配一整套空间核（$D_K^2$ 被乘了 $N$ 次）。

**深度可分离**：

$$\underbrace{D_K^2 \cdot M}_{\text{depthwise（空间）}} \times D_F^2 + \underbrace{M \cdot N}_{\text{pointwise（通道）}} \times D_F^2 = M(D_K^2 + N) \cdot D_F^2$$

空间和通道**相加**——空间核只配 $M$ 个（每通道一个），不乘 $N$。

$$\boxed{\frac{\text{可分离}}{\text{标准}} = \frac{1}{N} + \frac{1}{D_K^2} \approx \frac{1}{9} \quad (D_K=3, N \gg 9)}$$

**比喻**：原来两个人（空间+通道）要互相请客（相乘），现在各付各的（相加）。$3 \times 3$ 卷积从 $9$ 倍代价降到 $9+1=10$ 份中的 $1$ 份。

#### 两个部署旋钮

- **宽度乘子 $\alpha$**：通道 $M \to \alpha M$，计算量 $\sim \alpha^2$
- **分辨率乘子 $\rho$**：特征图 $D_F \to \rho D_F$，计算量 $\sim \rho^2$

### 效果

- 4.2M 参数，569M 乘加，ImageNet 70.6% top-1
- 同精度下比 GoogLeNet 省一半参数和计算量
- **深度可分离卷积成为移动端 CNN 标准积木**

## 阶段 5：ResNeXt (2017) —— "请团队，不请全才"

### 一句话记忆

> **ResNeXt = ResNet 是一个"全才"干活；ResNeXt 请 32 个"专才"各干各的，最后汇总。因为共享了工具(1×1 卷积)，32 个专才的代价远小于 32 个独立团队**

### 通俗比喻

ResNet 的一个 block 像请一个"全才"，什么都会干，但一个人能力有限，干多了边际收益递减（加宽）。

ResNeXt 请 32 个"专才"，每人只学一种技能（同构分支、同构多路），32 种技能汇总起来比一个全才强得多。

**为什么不像集成 32 个独立网络？** 因为这 32 个专才**共享工具**（首尾的 1×1 卷积是共享的），只有中间的 3×3 各做各的。所以 32 个专才的代价远小于 32 个独立团队。

### 痛点

增加深度和宽度都有天花板。Inception 证明"多路并行"更有效，但每个分支要人工设计，不可扩展。

### Idea：Cardinality——第三个维度

$$\mathcal{F}(x) = \sum_{i=1}^{C} \tau_i(x) \quad \text{（C 条同构路径，求和聚合）}$$

把 Inception 的"split-transform-merge"抽象出来，去掉人工设计的分支差异，让所有分支**同构**，用 $C$ 控制"开几路"。

#### 三种等价形式（数学核心）

ResNeXt block 可以写成三种等价形式：

| 形式 | 描述 |
|------|------|
| 多分支式 | $C$ 条独立 bottleneck，显式写出 |
| **分组卷积式** | 3×3 用 grouped conv（$C$ 组） |
| 紧凑式 | 合并操作 |

**关键等价**：**多分支 = 分组卷积**。分组卷积就是"$C$ 组各自独立卷积"的高效实现。

**比喻**：Inception 式多分支 = 32 条路显式画出（直观但占地方）。分组卷积 = 一条路分 32 条车道（高效，GPU 支持）。

#### 为什么 cardinality 比加宽更有效？

| | 加宽 | 加基数 |
|---|---|---|
| 做法 | 单路通道变多 | 开 $C$ 路同构分支 |
| 效果 | 一个变换学更复杂（边际递减） | 学 $C$ 种不同变换（接近集成） |
| 比喻 | 一个人干更重的活（累） | 多请几个人各干各的（效率高） |

#### C 路聚合 vs 集成 C 个网络

| | ResNeXt | 集成 |
|---|---|---|
| 共享工具 | 首尾 1×1 共享 | 各自独立 |
| 参数 | 25M | 800M |
| 训练 | 1 次 | C 次 |
| 残差基座 | C 路共享 $x$ | 各自从零学 |

### 效果

- 相同参数量下一致优于 ResNet（ResNeXt-50: 21.2% vs ResNet-50: 22.1%）
- SE-ResNeXt 赢 ILSVRC 2017 冠军

| ResNet v1 | 高速公路 | $\mathcal{F}(x)+x$，加法梯度链，"+1"兜底 |
| ResNet v2 | 拆掉收费站 | pre-activation，纯恒等高速公路 |
| DenseNet | 文件夹不覆盖 | concat 显式保留所有历史特征 |
| MobileNet | 拆两人各付各的 | 空间和通道解耦，乘积变求和，计算量降 1/9 |
| ResNeXt | 请团队不请全才 | cardinality 多路同构≈微集成 |

## 全局因果链

```
AlexNet (2012): ReLU+Dropout+GPU → 深度学习可行
    │
    ├─ 大核无规范 → VGG: 统一 3×3 小核
    │     └─ 深层训练困难 → Xavier: 方差一致(调音器)
    │           └─ 对 ReLU 失效 → He: 翻倍补偿(砍半翻倍)
    │                 └─ 深度退化(30层<14层) → ↓
    │
    ├─ 计算量爆炸+单尺度 → NIN: 1×1卷积+GAP
    │     └─ 1×1降维 → GoogLeNet: Inception多分支+bottleneck
    │
    ├─ 分布漂移(ICS) → BN: 每层恒温器
    │     └─ 14倍加速 + 正则化
    │
    ├─ 退化问题 → ResNet v1: 高速公路(残差+加法链)
    │     └─ 高速有收费站 → ResNet v2: 拆收费站(pre-activation)
    │           ├─ add→concat → DenseNet: 文件夹(特征复用)
    │           ├─ 解耦空间+通道 → MobileNet: 拆两人(乘积变求和)
    │           └─ 多路同构 → ResNeXt: 请团队(cardinality)
```
