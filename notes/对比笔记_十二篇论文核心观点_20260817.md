# 十二篇论文核心观点对比

> 涵盖论文（按演进顺序）：
> 1. AlexNet (2012) 2. VGG (2014) 3. Xavier (2010) 4. He (2015)
> 5. NIN (2014) 6. GoogLeNet (2014) 7. BN (2015)
> 8. ResNet v1 (2016) 9. ResNet v2 (2016)
> 10. DenseNet (2017) 11. MobileNet (2017) 12. ResNeXt (2017)
>

## 一、总览对比

| # | 论文 | 年份/会议 | 一句话核心 | 核心改进点 |
|---|------|----------|-----------|-----------|
| 1 | AlexNet | 2012 / NeurIPS | ReLU+Dropout+GPU 开启深度学习 | ReLU 替代 sigmoid，Dropout 防过拟合 |
| 2 | VGG | 2014 / ICLR | $3 \times 3$ 小核级联 | 多个小核替代大核，减少参数+增加非线性 |
| 3 | Xavier | 2010 / AISTATS | 方差一致初始化 | $\text{Var}(W)=\frac{2}{n_{\text{in}}+n_{\text{out}}}$ |
| 4 | He | 2015 / ICCV | ReLU 初始化翻倍补偿 | $\text{Var}(W)=\frac{2}{n}$，PReLU |
| 5 | NIN | 2014 / arXiv | 1×1 卷积 + GAP | mlpconv 跨通道非线性融合 |
| 6 | GoogLeNet | 2014 / CVPR | Inception 多分支 + 1×1 降维 | 多尺度并行，bottleneck 降计算量 |
| 7 | BN | 2015 / ICML | 每层特征图归一化 | $\hat{x}=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}$，$\gamma\hat{x}+\beta$ |
| 8 | ResNet v1 | 2016 / CVPR | 残差学习 + 加法梯度链 | $\mathcal{F}(x)+x$，152 层可训练 |
| 9 | ResNet v2 | 2016 / ECCV | pre-activation 纯恒等 | 移除 add 后 ReLU，1000 层可训练 |
| 10 | DenseNet | 2017 / CVPR | add→concat 特征复用 | dense connectivity + growth rate |
| 11 | MobileNet | 2017 / arXiv | 深度可分离卷积 | 空间+通道解耦，计算量降 1/9 |
| 12 | ResNeXt | 2017 / CVPR | cardinality 第三维度 | 同构多路聚合 = 分组卷积 |

## 二、痛点驱动对比（每篇解决了什么）

| 论文 | 前人遇到的痛点 | 为什么这么做 |
|------|--------------|-------------|
| AlexNet | sigmoid 饱和+梯度消失+过拟合+CPU 太慢 | ReLU 无饱和区；Dropout 防过拟合；GPU 并行 |
| VGG | AlexNet 大核无规范，参数多 | 小核级联感受野等效但参数更少、非线性更多 |
| Xavier | 随机初始化方差逐层衰减→信号消失 | 推导方差一致公式，让信号不放大不衰减 |
| He | Xavier 线性假设对 ReLU 不成立 | ReLU 砍半信号→方差翻倍补偿 |
| NIN | 线性滤波器抽象能力不足 | 1×1 卷积=微型 MLP，跨通道非线性融合 |
| GoogLeNet | 计算量爆炸+单尺度感受野 | 多分支并行多尺度+1×1 降维减计算量 |
| BN | 深层输入分布漂移(ICS)→死锁 | 每层归一化拉回分布，梯度流过归一化 |
| ResNet v1 | 退化问题(深网络训练集误差变大) | 学残差让恒等映射易达，加法链梯度直通 |
| ResNet v2 | v1 的 post-activation ReLU 阻断恒等 | pre-activation 移除 add 后 ReLU |
| DenseNet | ResNet add 可能覆盖浅层特征 | concat 显式保留所有历史特征 |
| MobileNet | 标准卷积太贵，移动端跑不动 | 解耦空间特征与通道特征，拆成 depthwise(空间)+pointwise(通道) |
| ResNeXt | 加深加宽有天花板 | cardinality 多路同构，接近集成更有效 |

## 三、阶段内对比

### 3.1 阶段 1：VGG vs Xavier vs He

| 维度 | VGG | Xavier | He |
|------|-----|--------|-----|
| 研究角度 | 网络结构 | 权重初始化 | 初始化+激活函数 |
| 核心问题 | 大核无规范 | 深度网络为何难训练 | ReLU 网络怎么初始化 |
| 核心公式 | 两个 $3 \times 3$ = 一个 $5 \times 5$ | $\text{Var}(W)=\frac{2}{n_{\text{in}}+n_{\text{out}}}$ | $\text{Var}(W)=\frac{2}{n}$ |
| 关键假设 | — | $f'(0)=1$（线性） | ReLU 砍半信号($\frac{1}{2}$) |
| 适用 | 通用 | tanh | ReLU |
| 局限 | 参数多，仍需预训练 | 对 ReLU 失效 | 深度退化→ResNet |

### 3.2 阶段 2：NIN vs GoogLeNet

| 维度 | NIN | GoogLeNet |
|------|-----|-----------|
| 1×1 卷积用途 | 增强非线性(微型 MLP) | 降维(bottleneck) |
| 分类头 | GAP（首创） | GAP（采用） |
| 多尺度 | 无 | 1×1/3×3/5×5 并行 |
| 参数量 | ~1M | ~5M |
| 参数减少 | 无 | 85%+（1×1 降维） |
| 后续影响 | 1×1+GAP 成标配 | bottleneck 被 ResNet 继承 |

### 3.3 阶段 4：ResNet v1 vs v2

| 维度 | ResNet v1 | ResNet v2 |
|------|-----------|-----------|
| block 顺序 | Conv→BN→ReLU→Conv→BN→**add→ReLU** | **BN→ReLU→Conv→BN→ReLU→Conv→add** |
| add 后 | ReLU（瓶颈） | 无（纯恒等） |
| $f$ | $\text{ReLU}$ | $\text{identity}$ |
| 前向递推 | 嵌套 $f(f(\dots))$ | 干净求和 $x_L = x_l + \sum \mathcal{F}$ |
| 反向梯度 | ReLU 门控可清零 "+1" | "+1" 永远在 |
| 可训深度 | 152 层 | 1000 层 |

### 3.4 阶段 5：DenseNet vs MobileNet vs ResNeXt

| 维度 | DenseNet | MobileNet | ResNeXt |
|------|---------|-----------|---------|
| 痛点 | add 特征覆盖 | 标准卷积太贵 | 加深加宽有天花板 |
| 核心改进 | add→concat | depthwise+pointwise | cardinality 多路 |
| 1×1 角色 | 隔离 3×3 与增长 | 独立通道融合 | 分组前后变换 |
| 效率指标 | 65% 参数同精度 | 1/9 计算量 | 相同参数更高精度 |
| 参数量 | 28.9M (DenseNet-161) | 4.2M | 25M (ResNeXt-50) |
| ImageNet top-1 | 77.6% | 70.6% | 78.8% |

## 四、跨阶段对比

### 4.1 1×1 卷积的角色演进

| 论文 | 1×1 卷积角色 | 核心目的 |
|------|-------------|---------|
| NIN | 增强非线性（堆叠成 MLP） | 跨通道融合 |
| GoogLeNet | 降维（bottleneck） | 减计算量 85%+ |
| ResNet | bottleneck 辅助 3×3 | 深层 block 标准件 |
| DenseNet | 隔离 3×3 与增长输入 | 压住平方增长 |
| MobileNet | 独立承担通道融合 | 解耦空间和通道 |
| ResNeXt | 分组前后通道变换 | 配合 grouped conv |

> 共同 pattern：用便宜的 1×1 处理维度变换，把贵的 3×3 锁在固定预算。

### 4.2 梯度稳定方法对比

| 方法 | 作用阶段 | 机制 | 局限 |
|------|---------|------|------|
| Dropout | 训练全程 | 随机失活→等效集成 | 推理需缩放 |
| Xavier/He | 仅第 0 步 | 设定初始方差 | 训练后被破坏 |
| BN | 训练全程 | 每步重新归一化 | batch 依赖 |
| ResNet 加法链 | 训练全程 | "+1" 兜底 | post-act 有收费站 |
| Pre-activation | 训练全程 | 纯恒等高速公路 | — |
| DenseNet 多路径 | 训练全程 | 每层梯度多路直达 | 通道增长 |

### 4.3 特征传递方式对比

| 论文 | 特征如何传递 | 信息保留 |
|------|-------------|---------|
| VGG | 层层串行 | 否（每层重新组织） |
| ResNet | 残差相加 $x+\mathcal{F}(x)$ | 部分（被求和稀释） |
| DenseNet | 拼接 $[x_0,\dots,x_{l-1}]$ | 是（显式保留） |
| ResNeXt | C 路同构聚合 $\sum \tau_i$ | C 种变换独立 |

### 4.4 效率改进对比

| 论文 | 效率改进 | 代价/局限 |
|------|---------|----------|
| GoogLeNet | 1/12 参数(vs VGG) | 结构复杂 |
| BN | 14 倍训练加速 | batch 依赖 |
| DenseNet | 65% 参数同精度 | 通道增长 |
| MobileNet | 1/9 计算量 | 精度略降 |
| ResNeXt | 相同参数更高精度 | 分组实现 |

## 五、传承关系图

```
AlexNet (2012) ─── ReLU + Dropout + GPU
    │
    ├──→ VGG (2014): 统一 3×3 小核
    │        └──→ (深层训练困难)
    │              ├──→ Xavier (2010): 方差一致 ──→ He (2015): ReLU 翻倍
    │              │                                  └──→ 深度退化 ──→ ResNet
    │              │
    ├──→ NIN (2014): 1×1卷积 + GAP
    │        └──→ GoogLeNet (2014): Inception + 1×1降维
    │                  └──→ bottleneck ──→ ResNet / DenseNet / ResNeXt
    │
    ├──→ BN (2015): 每层归一化
    │        └──→ 14倍加速 + 正则化
    │
    ├──→ ResNet v1 (2016): 残差 + 加法链
    │        ├──→ ResNet v2 (2016): pre-activation
    │        ├──→ DenseNet (2017): add→concat
    │        ├──→ ResNeXt (2017): cardinality 多路
    │        └──→ MobileNet (2017): 深度可分离（独立方向）
```

## 六、设计哲学对比

| 论文 | 哲学 | 核心洞察 |
|------|------|---------|
| AlexNet | 工程突破 | ReLU+GPU+大数据三件套 |
| VGG | 简洁规范 | 小核级联=更少参数+更多非线性 |
| Xavier | 理论先行 | 控制方差→信号稳定传播 |
| He | 修正假设 | ReLU 砍半→初始化翻倍 |
| NIN | 功能增强 | 线性不够→用 MLP |
| GoogLeNet | 效率优先 | 多尺度+降维=1/12 参数 |
| BN | 全程修正 | 不只初始化，每步都归一化 |
| ResNet v1 | 残差思想 | 学差量比学全量容易 |
| ResNet v2 | 恒等优先 | 移除一切阻断恒等的操作 |
| DenseNet | 复用优先 | 拼接保留全部，不揉在一起 |
| MobileNet | 解耦思想 | 空间和通道各付各的 |
| ResNeXt | 维度拓展 | 多路同构≈微集成，比加宽更有效 |
