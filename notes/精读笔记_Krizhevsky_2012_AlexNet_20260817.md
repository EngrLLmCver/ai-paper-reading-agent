# 精读笔记：AlexNet (Krizhevsky et al., 2012)

## 一、论文速览

- **标题**：ImageNet Classification with Deep Convolutional Neural Networks
- **作者**：Alex Krizhevsky, Ilya Sutskever, Geoffrey Hinton (多伦多大学)
- **发表**：NeurIPS 2012
- **定位**：现代深度学习的破局之作——首次证明深度 CNN + 大数据 + GPU 可大幅超越传统方法，开启 2012 年后的深度学习时代。
- **关键词**：ReLU、Dropout、GPU、Data Augmentation、AlexNet

---

## 二、痛点

- 传统 ML 依赖手工特征（SIFT/HOG），泛化差、耗时长
- sigmoid 在深层网络中饱和→梯度消失
- 无有效正则化→深网络过拟合严重
- CPU 训练太慢，60M 参数的网络无法训练

---

## 三、核心改进

| 改进点 | 做法 | 解决什么问题 |
|--------|------|-------------|
| **ReLU 激活** | $\max(0,x)$ 替代 sigmoid/tanh | 无饱和区→梯度不消失；训练快 6 倍 |
| **Dropout** | 训练时随机置零 50% 神经元 | 防过拟合（等效集成多个稀疏网络） |
| **GPU 并行** | 2 块 GTX 580 (3GB) 双卡并行 | 突破算力瓶颈 |
| **大数据** | ImageNet 120 万训练图 | 足够数据喂饱 60M 参数 |
| **数据增强** | 随机裁剪+水平翻转+PCA 颜色扰动 | 扩充数据量 2048 倍，减少过拟合 |
| **局部响应归一化 (LRN)** | 跨通道归一化响应 | 抑制过大的通道响应（后被 BN 取代） |
| **重叠池化** | $3 \times 3$ 步长 2 的池化 | 减少信息损失，略提升精度 |

### 3.1 ReLU 为什么比 sigmoid 快

$$\text{sigmoid}'(z) \leq 0.25, \quad \text{ReLU}'(z) \in \{0, 1\}$$

sigmoid 每层梯度缩 4 倍→深层必然消失。ReLU 正区间梯度恒 1→梯度不衰减。

### 3.2 Dropout 的机制

训练时每个神经元有 $p=0.5$ 概率被置零→每次前向用不同子网络→等效训练指数级个稀疏网络。推理时全部使用，权重乘 $(1-p)$ 缩放。

### 3.3 双 GPU 架构

由于当时单卡 3GB 显存不够，AlexNet 把网络分成两半，分别在两块 GPU 上训练，中间在特定层交叉通信。这是**工程妥协**，今天已不重要。

---

## 四、网络架构

```
输入 227×227×3
    │
    ├─ Conv1: 96核, 11×11, stride 4 → 55×55×96 (split 48+48)
    │  ReLU → LRN → MaxPool 3×3 s2 → 27×27×96
    │
    ├─ Conv2: 256核, 5×5, pad 2 → 27×27×256
    │  ReLU → LRN → MaxPool 3×3 s2 → 13×13×256
    │
    ├─ Conv3: 384核, 3×3, pad 1 → 13×13×384 (跨GPU通信)
    │  ReLU
    ├─ Conv4: 384核, 3×3, pad 1 → 13×13×384
    │  ReLU
    ├─ Conv5: 256核, 3×3, pad 1 → 13×13×256
    │  ReLU → MaxPool 3×3 s2 → 6×6×256
    │
    ├─ FC6: 4096 (+ Dropout)
    ├─ FC7: 4096 (+ Dropout)
    └─ FC8: 1000 (softmax)
```

- 5 个卷积层 + 3 个全连接层
- 60M 参数，650K 神经元

## 五、实验结果

| 方法 | ImageNet 2012 top-5 错误率 |
|------|--------------------------|
| 第二名（传统方法） | 26.2% |
| **AlexNet** | **15.3%** |

领先第二名近 11 个百分点，震惊学术界。

---

## 六、效果与遗产

- 开启现代深度学习时代
- ReLU 成为默认激活函数
- Dropout 成为正则化标配
- GPU 训练深度网络成为标准范式
- ImageNet 成为图像识别标准基准

### 遗留问题

- 大卷积核（$11 \times 11$、$7 \times 7$）无统一规范→VGG 规范化
- 深层训练仍不稳→Xavier/He 初始化
- LRN 效果有限→BN 取代
- 全连接层参数太多→GAP 替代

## 七、术语表

| 术语 | 解释 |
|------|------|
| ReLU | $\max(0,x)$，无饱和区，梯度恒 0 或 1 |
| Dropout | 随机置零神经元，等效集成，防过拟合 |
| LRN | 局部响应归一化，跨通道抑制，后被 BN 取代 |
| Data Augmentation | 随机裁剪/翻转/颜色扰动，扩充数据 |
