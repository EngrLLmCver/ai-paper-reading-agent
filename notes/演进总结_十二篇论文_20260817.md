# 深度学习经典论文演进总结：从 AlexNet 到 ResNeXt（2012-2017）

> 涵盖论文（按阅读指南演进顺序）：
> AlexNet → VGG → Xavier → He → NIN → GoogLeNet → BN → ResNet v1 → ResNet v2 → DenseNet → MobileNet → ResNeXt
>
> 创建日期：2026-08-17

---

## 〇、演进主线：两条双螺旋

2012-2017 年间的深度学习演进，本质是围绕**两条主线**展开的：

```
【主线 1：网络表达能力（变深、变强）】
AlexNet(2012) → VGG(2014) → NIN/GoogLeNet(2014) → ResNet v1(2016) → ResNet v2(2016) → DenseNet(2017) → ResNeXt(2017)
     │              │              │                  │                │                │              │
     ▼              ▼              ▼                  ▼                ▼                ▼              ▼
【主线 2：优化与梯度稳定（数值控制）】
Dropout → Xavier(2010) → He(2015) → BN(2015) → Pre-activation → (特征复用/轻量化)
(防过拟合) (方差稳定)  (ReLU补偿) (分布归一化) (恒等高速公路)
```

- **主线 1** 回答"网络怎么变深变强"
- **主线 2** 回答"变深之后梯度怎么稳住"
- 两者交替推进：每当主线 1 往前推一步，主线 2 就要跟上解决新暴露的优化问题

还有一条**暗线**贯穿始终：**1×1 卷积**从 NIN 起被反复赋予不同角色（增强非线性 → 降维 → bottleneck → 隔离增长 → 独立通道融合 → 分组前后变换）。

## 阶段 0：破局——AlexNet (2012)

### 时代背景

2012 年前，图像识别依赖手工特征（SIFT、HOG）+ 浅层模型（SVM）。深度网络被认为不可训练——梯度消失、计算量太大、容易过拟合。

### 前人痛点

- 手工特征设计耗时，泛化差
- sigmoid 激活函数在深层网络中饱和→梯度消失
- 无有效正则化手段→过拟合严重
- CPU 训练太慢

### Idea 与核心改进

| 改进点 | 具体做法 | 解决什么问题 |
|--------|---------|-------------|
| **ReLU 激活** | 用 $\max(0,x)$ 替代 sigmoid/tanh | 解决饱和区梯度消失；训练速度提升 6 倍 |
| **Dropout** | 训练时随机置零 50% 神经元 | 防止过拟合（等效于集成多个稀疏网络） |
| **GPU 并行** | 用 2 块 GTX 580 (3GB) 并行训练 | 突破计算瓶颈，训练 60M 参数网络 |
| **大数据** | ImageNet 120 万张训练图 | 足够数据喂饱大网络，缓解过拟合 |
| **局部响应归一化 (LRN)** | 跨通道归一化 | 抑制响应过大的通道（后来被 BN 取代） |
| **大卷积核** | 第一层用 $11 \times 11$ | 适应大输入图像（$227 \times 227$） |

### 效果与遗产

- ImageNet 2012 top-5 错误率 **15.3%**，比第二名（26.2%）领先近 11 个百分点
- **开启深度学习时代**：证明深度 CNN + 大数据 + GPU 可行
- ReLU 成为默认激活函数；Dropout 成为正则化标配
- 遗留问题：大卷积核无规范、深层训练仍不稳→催生 VGG 和 Xavier

## 阶段 1：标准化与深度探索——VGG + Xavier + He

### 时代背景

AlexNet 证明深度网络可行，但存在两个问题：①架构随意（大核、无统一规范）；②深层仍训练困难（梯度不稳定）。

### 1.1 VGG (Simonyan & Zisserman, 2014)

#### 前人痛点

AlexNet 用 $11 \times 11$、$7 \times 7$ 等大卷积核，缺乏统一规范，且大核参数多、计算贵。

#### Idea 与核心改进

**核心思想：用多个小核级联替代大核。**

两个 $3 \times 3$ 卷积堆叠的感受野 = 一个 $5 \times 5$；三个 $3 \times 3$ 堆叠 = 一个 $7 \times 7$。

| 对比 | 一个 $5 \times 5$ | 两个 $3 \times 3$ 堆叠 |
|------|------------------|----------------------|
| 感受野 | $5 \times 5$ | $5 \times 5$（相同） |
| 参数量 | $25 C^2$ | $18 C^2$（少 28%） |
| 非线性 | 1 次 ReLU | 2 次 ReLU（更强判别力） |

#### 核心改进

- 统一用 $3 \times 3$ 小核，所有层统一规范
- 深度推进到 16-19 层
- 用预训练初始化（先训浅的，再迁移到深的）

#### 效果与遗产

- ImageNet 2014 亚军（top-5 错误率 7.3%）
- **$3 \times 3$ 小核成为后续所有网络的标准**
- 参数量 138M（绝大多数在全连接层）→启发了 GAP 替代 FC
- 仍需预训练初始化，未从根上解决训练问题→Xavier 和 He 接力

### 1.2 Xavier 初始化 (Glorot & Bengio, 2010)

#### 前人痛点

随机初始化（$\text{Var}(W) = \frac{1}{3n}$）导致前向激活方差逐层缩小到 $\frac{1}{3}$，反向梯度方差也逐层衰减→深层网络信号消失。

#### Idea 与核心改进

**核心思想：让每层输入输出方差一致，信号不放大不衰减。**

前向稳定：$\text{Var}(W) = \frac{1}{n_{\text{in}}}$

反向稳定：$\text{Var}(W) = \frac{1}{n_{\text{out}}}$

两者折中（调和平均）：

$$\text{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}}$$

#### 关键假设

$f'(0) = 1$（激活函数在零点近似线性）：
- 对 tanh ✅ 成立
- 对 sigmoid ❌ $f'(0) = 0.25$（偏小）
- 对 ReLU ❌ 不成立（一半导数为零）

#### 效果与遗产

- 深度网络可从零训练，无需预训练
- 但对 ReLU 不适用→He 修正
- 建立了"方差分析"的方法论框架

### 1.3 He 初始化 (He et al., 2015)

#### 前人痛点

Xavier 的线性假设 $f'(0)=1$ 对 ReLU 不成立。ReLU 把一半信号置零，导致 $\text{Var}(a) = \frac{1}{2}\text{Var}(z)$，信号每层减半。

#### Idea 与核心改进

**核心修正：ReLU 砍掉一半信号，初始化方差要翻倍补偿。**

$$E[a^2] = \frac{1}{2}E[z^2] \Rightarrow \text{Var}(W) = \frac{2}{n}$$

与 Xavier 对比（$n_{\text{in}}=n_{\text{out}}$ 时）：$\text{He} = 2 \times \text{Xavier}$，刚好补偿 ReLU 的 $\frac{1}{2}$。

同时还提出 **PReLU**：负半轴斜率 $a$ 可学习，额外参数极少但提升明显。

#### 诚实负面结果：深度退化

He 初始化让 30 层能训练了，但 30 层比 14 层**更差**（训练集误差也更高）。这不是过拟合，不是梯度消失，是**优化本身的问题**——网络太深，连训练集都拟合不好。

#### 效果与遗产

- ImageNet top-5 错误率 4.94%，**首次超越人类水平**（5.1%）
- He 初始化成为 ReLU 网络的标准（PyTorch 默认）
- 深度退化问题→直接催生 ResNet

### 阶段 1 小结

| 论文 | 解决的问题 | 核心公式/改进 | 局限/遗留 |
|------|-----------|-------------|----------|
| VGG | 大核无规范 | $3 \times 3$ 小核级联 | 参数多，仍需预训练 |
| Xavier | 随机初始化方差失控 | $\text{Var}(W) = \frac{2}{n_{\text{in}}+n_{\text{out}}}$ | 对 ReLU 不成立 |
| He | Xavier 对 ReLU 失效 | $\text{Var}(W) = \frac{2}{n}$ | 深度退化→ResNet |

## 阶段 2：通道维度与多尺度——NIN + GoogLeNet

### 时代背景

VGG 证明可以加深，但一味堆 $3 \times 3$ 加深有两个问题：①计算量爆炸（参数量随深度线性增长）；②单尺度感受野无法捕捉不同大小的目标。

### 2.1 NIN (Lin et al., 2014)

#### 前人痛点

传统卷积 = 线性滤波器（内积）+ 非线性激活。隐含假设"概念是线性可分的"，但现实中的概念通常在非线性流形上，线性滤波器抽象能力不足。

#### Idea 与核心改进

| 改进点 | 做法 | 意义 |
|--------|------|------|
| **mlpconv 层** | 在 $3 \times 3$ 卷积后接 1×1 卷积+ReLU 堆叠成微型 MLP | 跨通道非线性融合，特征提取更强 |
| **全局平均池化 (GAP)** | 用整张特征图的全局平均替代全连接层 | 零参数分类头，天然防过拟合，特征图=类别置信度图 |

**1×1 卷积的三种等价视角**：①每个像素位置过微型 MLP；②跨通道加权线性组合；③标准 1×1 卷积。

**mlpconv 和 GAP 的配套关系**：mlpconv 产生强语义特征图，GAP 把特征图直接变成分类概率。两者缺一不可。

#### 效果与遗产

- CIFAR-10 错误率 10.41%（maxout 11.68%）
- **1×1 卷积**成为后续几乎所有网络的核心组件
- **GAP** 被 GoogLeNet、ResNet 等直接采用

### 2.2 GoogLeNet / Inception v1 (Szegedy et al., 2014)

#### 前人痛点

VGG 的 $3 \times 3$ 串行堆叠有两个缺陷：①计算量随深度二次增长；②单尺度感受野——一个固定大小的核无法同时捕捉小目标（边缘）和大目标（物体）。

#### Idea 与核心改进

| 改进点 | 做法 | 意义 |
|--------|------|------|
| **Inception 多分支并行** | 同时跑 $1 \times 1$、$3 \times 3$、$5 \times 5$、pool 四条路，拼接输出 | 多尺度感知，网络自己学各尺度权重 |
| **1×1 降维 (bottleneck)** | 在 $3 \times 3$/$5 \times 5$ 前插入 1×1 减少通道数 | 计算量降 85%+ |
| **GAP 替代 FC** | 直接采用 NIN 的 GAP | 省大量参数 |
| **辅助分类器** | 中间层接 2 个分类头，总损失 = 主 + 0.3×辅₁ + 0.3×辅₂ | 中间层注入梯度，缩短回传路径 |

**1×1 降维的威力**（256→64 通道，$5 \times 5$ 卷积）：

$$\text{直接：} 5 \times 5 \times 256 \times 64 = 409{,}600$$

$$\text{降维：} 1 \times 1 \times 256 \times 32 + 5 \times 5 \times 32 \times 64 = 59{,}392 \quad \text{（减少 85.5\%）}$$

**1×1 卷积的两种用途**（NIN vs GoogLeNet）：

| | NIN | GoogLeNet |
|---|---|---|
| 用途 | 增强非线性 | 降维 |
| 1×1 角色 | 微型 MLP 的组成单元 | bottleneck 降通道 |

#### 效果与遗产

- ImageNet 2014 双冠（top-5 错误率 6.67%），仅 5M 参数（VGG 的 1/28）
- **bottleneck（1×1 降维）** 被 ResNet、DenseNet 直接继承
- **多分支思想** 被 ResNeXt 推广为统一的"split-transform-merge"
- Inception 演进路线：v1→v2(+BN+分解大核)→v3(非对称卷积)→v4(+ResNet 连接)

### 阶段 2 小结

| 论文 | 解决的问题 | 核心改进 | 遗留 |
|------|-----------|---------|------|
| NIN | 线性滤波器抽象不足 | mlpconv(1×1增强非线性) + GAP | 只在小数据集验证 |
| GoogLeNet | 计算量大+单尺度 | Inception多分支 + 1×1降维 | 结构复杂，手工设计分支 |

## 阶段 3：归一化革新——Batch Normalization (2015)

### 时代背景

即使有了 He 初始化和 GoogLeNet 的 bottleneck，深层网络仍有一个被忽视的问题：**训练过程中，前层参数更新导致后层输入分布漂移**。

### 前人痛点：Internal Covariate Shift (ICS)

$$\text{参数更新} \;\rightarrow\; \text{下一层输入分布漂移} \;\rightarrow\; \text{ICS}$$

ICS 的三个后果：
1. 需要极小学习率
2. 依赖谨慎初始化
3. 饱和非线性（sigmoid）死锁：$z$ 漂移到饱和区→$g'(z)\to 0$→梯度消失→$W$ 不更新→$z$ 无法被拉回→死锁

### Idea 与核心改进

**核心思想：不要只在输入层归一化，在网络每个隐藏层特征图上都做归一化。**

BN 四步公式（mini-batch 统计）：

$$\mu_B = \frac{1}{m}\sum_{i=1}^m x_i, \quad \sigma_B^2 = \frac{1}{m}\sum_{i=1}^m (x_i - \mu_B)^2$$

$$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y_i = \gamma \hat{x}_i + \beta$$

| 设计要点 | 做法 | 为什么 |
|---------|------|--------|
| mini-batch 统计 | 用当前 batch 的均值方差 | 计算可行（不用全训练集） |
| γ, β 可学习 | 允许网络自己决定最佳分布 | 不降低网络容量（可表示恒等变换） |
| 归一化在计算图内 | 让梯度流过归一化 | 避免白化反例中 $b$ 更新被抵消 |
| 训练用 batch 统计，推理用移动平均 | 训练有噪声→正则化，推理确定性 | 兼顾优化和泛化 |

**为什么放弃了白化**：白化（去相关+标准化）是理想方案，但①协方差矩阵求逆 $O(d^3)$ 计算不可行；②梯度无法处理（$\mu,\Sigma$ 依赖 $W$）；③白化反例证明归一化不在计算图内会出问题。

**BN 解决 sigmoid 死锁的因果链**：

$$z \text{ 被 BN 拉回零均值单位方差} \rightarrow g'(z) \approx 0.25 \rightarrow \text{梯度正常回传} \rightarrow \text{死锁打破}$$

### 效果与遗产

- 训练步数减少 **14 倍**达到相同精度
- 5 倍学习率仍稳定训练
- BN-x5-Sigmoid 实验： sigmoid 网络 + BN 居然能训练→证明问题不在 sigmoid，在 ICS
- BN 同时起正则化作用（mini-batch 统计量的随机性注入噪声），消除 Dropout 需求
- **成为几乎所有现代深度网络的标配**
- 改善 Hessian 条件数 $\kappa = \lambda_{\max}/\lambda_{\min}$→各方向曲率均匀→大学习率可行

### 衔接到 ResNet

BN 稳定了分布，但**没有解决退化问题**——超过 20 层的网络训练集误差仍变大。BN 让训练更稳，但没有改变"深网络不好优化"的本质。ResNet 直接面对这个问题。

## 阶段 4：突破深度天花板——ResNet v1 + v2

### 时代背景

BN 解决了分布漂移，He 初始化解决了信号方差，但退化问题仍在：56 层 plain net 的训练集误差比 20 层还高。

### 4.1 ResNet v1 (He et al., CVPR 2016)

#### 前人痛点：退化问题

**不是过拟合（训练集误差也高），不是梯度消失（He+BN 已解决），是优化本身的问题**——深网络连训练集都拟合不好。

何恺明验证：理论上把 20 层后面接 36 层恒等映射就应至少不更差，但 plain net 做不到。

#### Idea 与核心改进

**核心思想：别学目标映射 $\mathcal{H}(x)$，学残差 $\mathcal{F}(x) = \mathcal{H}(x) - x$，用短路连接把 $x$ 加回来。**

$$\text{输出} = \mathcal{F}(x, \{W_i\}) + x$$

**为什么学残差更容易**：当最优解接近恒等映射时，学残差只需把 $\mathcal{F}$ 权重推向零（SGD 自然做到），而学原映射需精确拟合 $x \to x$（普通卷积很难）。

**梯度视角——加法 vs 乘法**：

| | Plain network | ResNet |
|---|---|---|
| 前向 | $x_{l+1} = \mathcal{F}(x_l)$（层层嵌套） | $x_{l+1} = x_l + \mathcal{F}(x_l)$（加法递推） |
| 反向梯度 | $\prod \frac{\partial x_{i+1}}{\partial x_i}$（连乘→消失/爆炸） | $1 + \frac{\partial \mathcal{F}}{\partial x_l}$（**"+1" 兜底**） |

**Bottleneck 结构**（深 ResNet 用）：$1 \times 1 \to 3 \times 3 \to 1 \times 1$，复用 GoogLeNet 的降维思想。

#### 效果与遗产

- 训练 **152 层**网络（比 VGG 深 8 倍），赢 ILSVRC 2015（top-5 错误率 3.57%）
- "加层至少不更差"这个理想在残差结构下可达
- 残差连接成为后续几乎所有现代架构的标准件

### 4.2 ResNet v2 / Pre-activation (He et al., ECCV 2016)

#### 前人痛点：v1 的短路通道不干净

v1 的 block：$\text{Conv} \to \text{BN} \to \text{ReLU} \to \text{Conv} \to \text{BN} \to \text{add} \to \text{ReLU}$

add 之后的 **ReLU 是瓶颈**——它是 post-activation（后激活）：

$$x_{l+1} = \text{ReLU}(x_l + \mathcal{F}(x_l))$$

- **前向**：恒等信号被 ReLU 截断负值→失真
- **反向**：$\text{ReLU}'$ 是门控，当 $x_l + \mathcal{F} < 0$ 时 "+1" 梯度被清零→高速公路有收费站

#### Idea 与核心改进

**核心修正：把 BN 和 ReLU 从 add 之后搬到 conv 之前（pre-activation），让短路变成纯恒等。**

| | v1（后激活） | v2（预激活） |
|---|---|---|
| block 顺序 | Conv→BN→ReLU→Conv→BN→**add→ReLU** | **BN→ReLU→Conv→BN→ReLU→Conv→add** |
| add 之后 | 有 ReLU（瓶颈） | **什么都没有** |
| $f$（add 后函数） | $\text{ReLU}$（非恒等） | $\text{identity}$（恒等） |

当 $f = \text{identity}$ 时，前向可干净展开：

$$x_L = x_l + \sum_{i=l}^{L-1} \mathcal{F}(x_i, W_i)$$

纯加法递归——任意深度都没有收费站。

#### 效果与遗产

- 1000 层网络可训练
- 理论分析了恒等映射在残差网络中的作用
- pre-activation 成为深层 ResNet 的标准结构

### 阶段 4 小结

| 论文 | 解决的问题 | 核心改进 | 遗留 |
|------|-----------|---------|------|
| ResNet v1 | 退化问题 | 残差学习 $\mathcal{F}(x) + x$，加法梯度链 | post-activation 阻断恒等路径 |
| ResNet v2 | v1 短路不干净 | pre-activation，纯恒等高速公路 | 残差是"加"→DenseNet 改"拼" |

## 阶段 5：残差的延续与轻量化——DenseNet + MobileNet + ResNeXt

### 时代背景

ResNet 证明残差连接是突破深度天花板的关键。但还有两个方向未探索：①残差的"加"能不能改成"拼"？②网络怎么在移动端跑？

### 5.1 DenseNet (Huang et al., CVPR 2017)

#### 前人痛点

ResNet 的 add 有两个隐患：
1. **特征覆盖**：$x + \mathcal{F}(x)$ 相加可能干扰浅层特征
2. **信息压缩**：add 后通道数不变，历史特征被"揉"进求和结果，无法显式调用

#### Idea 与核心改进

**核心修正：把"相加（Add）"改为"拼接（Concat）"，每一层连到后面所有层。**

$$x_l = H_l\big([x_0, x_1, \dots, x_{l-1}]\big)$$

| 机制 | 做法 | 解决什么 |
|------|------|---------|
| Dense connectivity | 每层输入 = 前面所有层拼接 | 特征显式保留，不丢失 |
| Growth rate $k$ | 每层只产生 $k$ 个新通道（典型 32） | 瘦层，省参数 |
| Bottleneck | 1×1 降维到 $4k$ 再 3×3 | 压住计算量平方增长 |
| Transition | block 间 1×1 Conv + 2×2 AvgPool | 降空间+压通道 |
| Compression $\theta$ | Transition 压通道到 $\theta$ 倍 | 进一步省参数 |

**计算量控制**：不加 bottleneck 时 3×3 卷积计算量 $\sim O(k^2 L^2)$（平方增长）。加 bottleneck 后：

- 1×1 卷积（随 $l$ 增长，但便宜）：$\propto (k_0 + k(l-1)) \times 4k$
- 3×3 卷积（**常数，不随 $l$ 增长**）：$\propto 4k \times k \times 9 = 36k^2$

贵的 3×3 被锁定在固定预算，增长推给便宜的 1×1。

**DenseNet vs ResNet 的参数效率**：DenseNet-161 用 28.9M 参数达到 ResNet-101（44.5M）同等精度。

#### 效果与遗产

- CVPR 2017 Best Paper
- 特征复用成为后续架构核心理念
- "瘦层 + 拼接积累"的设计哲学影响 EfficientNet 等

### 5.2 MobileNet v1 (Howard et al., 2017)

#### 前人痛点

标准卷积计算量随通道数平方增长（$D_K^2 \cdot M \cdot N \cdot D_F^2$），ResNet/DenseNet 无法在移动端运行。

#### Idea 与核心改进

**核心思想：标准卷积同时做空间滤波和通道融合，把它们拆开各做各的 -> 解耦空间特征和通道特征。**

| 步骤 | 做什么 | 核形状 |
|------|--------|--------|
| Depthwise | 每通道独立空间卷积 | $D_K \times D_K \times 1$，共 $M$ 个 |
| Pointwise | 1×1 卷积做通道融合 | $1 \times 1 \times M$，共 $N$ 个 |

**计算量推导——乘积变求和（数学核心）**：

标准卷积（空间×通道，**耦合相乘**）：

$$D_K^2 \cdot M \cdot N \cdot D_F^2$$

深度可分离（空间+通道，**解耦相加**）：

$$D_K^2 \cdot M \cdot D_F^2 + M \cdot N \cdot D_F^2 = M(D_K^2 + N) \cdot D_F^2$$

降比：

$$\frac{1}{N} + \frac{1}{D_K^2} \approx \frac{1}{9} \quad (D_K = 3, N \gg 9)$$

**两个部署旋钮**：宽度乘子 $\alpha$（压通道，$\sim \alpha^2$）和分辨率乘子 $\rho$（压特征图，$\sim \rho^2$）。

**1×1 卷积角色的升级**：在 NIN/GoogLeNet/ResNet 中 1×1 是"降维辅助"，在 MobileNet 中升格为**独立承担通道融合的正式一步**。

#### 效果与遗产

- 4.2M 参数，569M 乘加，ImageNet 70.6% top-1
- 同精度下比 GoogLeNet 省一半参数和计算量
- 深度可分离卷积成为移动端 CNN 标准积木
- MobileNet v2（倒残差）、v3（NAS+SE）建立其上

### 5.3 ResNeXt (Xie et al., CVPR 2017)

#### 前人痛点

增加深度和宽度都有天花板（边际收益递减）。GoogLeNet 的 Inception 证明"多路并行"更有效，但每个分支要人工设计，不可扩展。

#### Idea 与核心改进

**核心思想：把 Inception 的"split-transform-merge"抽象出来，去掉人工设计差异，让所有分支同构，用基数 $C$ 控制开几路。**

$$\mathcal{F}(x) = \sum_{i=1}^{C} \tau_i(x) \quad \text{（C 条同构路径，求和聚合）}$$

记号：ResNeXt-50（32×4d）= $C=32$ 路，每路宽 $d=4$，共 $32 \times 4 = 128$ 通道。

**三种等价形式**（数学核心）：

| 形式 | 描述 | 实现 |
|------|------|------|
| 多分支式 | $C$ 条独立 bottleneck 显式写出 | 直观但低效 |
| 分组卷积式 | 3×3 用 grouped conv（$C$ 组） | GPU 高效 |
| 紧凑式 | 合并操作 | 等价 |

**多分支 = 分组卷积**：分组卷积就是"$C$ 组各自独立卷积"的高效实现，等价于 $C$ 条同构路径。

**为什么 cardinality 比加宽更有效**：

| | 加宽 | 加基数 |
|---|---|---|
| 做法 | 单路通道变多 | 开 $C$ 路同构分支 |
| 效果 | 一个变换学更复杂（边际递减） | 学 $C$ 种不同变换（接近集成，收益更线性） |
| 类比 | 一个人干更重的活 | 多请几个人各干各的 |

**C 路聚合 vs 集成 C 个网络**：

| | ResNeXt | 集成 C 个网络 |
|---|---|---|
| 参数 | 25M（首尾 1×1 共享） | 800M（各自独立） |
| 训练 | 1 次 | C 次 |
| 集成粒度 | block 级微集成 | 网络级宏观集成 |
| 残差基座 | C 路共享 $x$（shortcut） | 各自从零学 |

#### 效果与遗产

- 相同参数量下一致优于 ResNet（ResNeXt-50: 21.2% vs ResNet-50: 22.1%）
- 分组卷积重回主流，cardinality 成为标准设计维度
- SE-ResNeXt 赢 ILSVRC 2017 冠军

### 阶段 5 小结

| 论文 | 解决的问题 | 核心改进 | 1×1 卷积角色 |
|------|-----------|---------|-------------|
| DenseNet | add 特征覆盖+信息压缩 | add→concat，特征复用 | 隔离 3×3 与增长输入 |
| MobileNet | 标准卷积太贵 | 深度可分离，乘积变求和 | 独立承担通道融合 |
| ResNeXt | 加深加宽有天花板 | cardinality 新维度 | 分组前后通道变换 |

## 贯穿全文的暗线

### 暗线 1：1×1 卷积的角色演进

1×1 卷积从 NIN 起被反复赋予不同角色，是理解整条演进线的钥匙：

| 论文 | 1×1 卷积的角色 | 核心目的 |
|------|---------------|---------|
| NIN (2014) | 增强非线性（堆叠成微型 MLP） | 跨通道特征融合 |
| GoogLeNet (2014) | 降维（bottleneck） | 减少计算量 85%+ |
| ResNet (2016) | bottleneck 降维辅助 3×3 | 深层 block 标准件 |
| DenseNet (2017) | 隔离 3×3 与增长输入 | 压住计算量平方增长 |
| MobileNet (2017) | 独立承担通道融合（pointwise） | 解耦空间和通道 |
| ResNeXt (2017) | 分组前后通道变换 | 配合 grouped conv |

> 共同 pattern：**用便宜的 1×1 卷积处理维度变换，把贵的 3×3 卷积锁在固定预算内。**

### 暗线 2：梯度稳定的演进

| 方法 | 作用阶段 | 机制 |
|------|---------|------|
| Dropout | 训练全程 | 随机失活→等效集成 |
| Xavier/He 初始化 | 仅第 0 步 | 设定初始方差 |
| BN | 训练全程 | 每步前向重新归一化 |
| ResNet 加法链 | 训练全程 | "+1" 兜底，梯度高速公路 |
| Pre-activation | 训练全程 | 移除收费站，纯恒等 |
| DenseNet 多路径 | 训练全程 | 每层梯度多路直达 |

> 初始化是一次性"起点修正"，BN/残差是每一步的"全程修正"。

### 暗线 3：效率的演进

| 论文 | 效率改进 | 代价 |
|------|---------|------|
| GoogLeNet | 1/12 参数（vs VGG） | 结构复杂 |
| BN | 14 倍训练加速 | 额外参数+batch 依赖 |
| DenseNet | 65% 参数达同精度 | 通道拼接增长 |
| MobileNet | 1/9 计算量 | 精度略降 |
| ResNeXt | 相同参数更高精度 | 分组卷积实现 |

### 暗线 4：特征复用的演进

| 论文 | 特征如何传递 | 信息是否保留 |
|------|-------------|-------------|
| VGG | 层层串行 | 否（每层重新组织） |
| ResNet | 残差相加 $x + \mathcal{F}(x)$ | 部分（被求和稀释） |
| DenseNet | 拼接 $[x_0, \dots, x_{l-1}]$ | **是（显式保留）** |
| ResNeXt | C 路同构聚合 | C 种变换独立保留 |

## 全局因果链（一张图理清）

```
AlexNet (2012): ReLU+Dropout+GPU → 深度学习可行
    │
    ├─ 大核无规范 → VGG: 统一 3×3 小核
    │     └─ 深层训练困难 → Xavier: 方差一致初始化 (2010)
    │           └─ 对 ReLU 失效 → He: 翻倍补偿 (2015)
    │                 └─ 深度退化(30层<14层) → ↓
    │
    ├─ 计算量爆炸+单尺度 → NIN: 1×1卷积+GAP (2014)
    │     └─ 1×1降维 → GoogLeNet: Inception多分支+bottleneck (2014)
    │
    ├─ 分布漂移(ICS) → BN: 每层归一化 (2015)
    │     └─ 14倍加速 + 正则化
    │
    ├─ 退化问题 → ResNet v1: 残差学习+加法梯度链 (2016)
    │     └─ post-activation阻断恒等 → ResNet v2: pre-activation (2016)
    │           ├─ add→concat → DenseNet: 特征复用 (2017)
    │           ├─ 多分支统一化 → ResNeXt: cardinality (2017)
    │           └─ 解耦空间+通道 → MobileNet: 深度可分离 (2017)
```
