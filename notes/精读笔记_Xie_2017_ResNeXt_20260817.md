# 精读笔记：ResNeXt (Xie et al., 2017)

## 一、论文速览

- **标题**：Aggregated Residual Transformations for Deep Neural Networks
- **作者**：Saining Xie, Ross Girshick, Piotr Dollár, Kaiming He (FAIR)
- **发表**：CVPR 2017
- **定位**：在 ResNet 的残差 block 基础上引入**基数（Cardinality）**作为深度和宽度之外的新设计维度，将 Inception 的"多路并行"抽象为统一、可扩展的同构多分支结构 -> 同构多路。
- **关键词**：Cardinality、Split-Transform-Merge、Grouped Convolution、Aggregated Residual

---

## 二、痛点

### 2.1 加深加宽都有天花板

| 路线 | 做法 | 问题 |
|---|---|---|
| 加深 | 增加层数 | 过 100 层收益递减，训练变慢 |
| 加宽 | 增加通道数 | 参数量平方增长，性价比低 |

### 2.2 Inception 有效但靠手调

GoogLeNet 的 Inception 证明"多路并行"比单纯加宽加深有效。但每个分支结构需人工设计（多大的卷积、几个通道、要不要 bottleneck），不可扩展。

> 痛点本质：深度和宽度是"连续可调"的设计维度，但"多路并行"这个更有效的方向一直靠人工经验，缺少统一、可量化、可扩展的维度来描述。

---

## 三、核心 Idea：Cardinality

### 3.1 第三个设计维度

把 Inception 的"split-transform-merge"模式抽象出来，去掉人工设计的分支差异，让所有分支拓扑相同，用**基数 $C$** 控制"开几路"。

$$\mathcal{F}(x) = \sum_{i=1}^{C} \tau_i(x) \quad \text{（C 条同构路径，求和聚合）}$$

对比 ResNet 的单路：

| | ResNet bottleneck | ResNeXt |
|---|---|---|
| 路径数 | 1 | $C$（典型 32） |
| 每路结构 | 1×1→3×3→1×1 | 1×1→3×3→1×1（相同） |
| 分支差异 | 无（只有一路） | **无（全部同构）** |
| 聚合 | 无（单路） | sum |

### 3.2 三原则

1. 产生相同尺寸特征图时，各路执行**相同操作**
2. 产生相同尺寸特征图时，各路**通道数相同**
3. 最后各路输出**相加**，再过 shortcut（和恒等映射$X_i$再$Add$）

### 3.3 记号：ResNeXt-50（32×4d）

- **32** = cardinality $C$
- **4** = 每路 bottleneck 宽度 $d$（3×3 每路 4 通道）
- **50** = 总层数

3×3 总通道 $= C \times d = 32 \times 4 = 128$，1×1 升维到 256。

---

## 四、数学重点：三种等价形式

### 形式一：Inception 式（多分支显式展开）

C 条独立 bottleneck，各 1×1→3×3→1×1，最后 sum。直观但实现低效。

### 形式二：分组卷积式（Grouped Convolution）

```
x (256ch) → 1×1 Conv (共享, 256→128) → 3×3 Grouped Conv (C=32组, 各组4ch) → 1×1 Conv (共享, 128→256) → + x
```

第二个 3×3 用**分组卷积**：128 通道分 $C=32$ 组，每组 4 通道独立卷积。这正是 C 路独立的高效实现。

### 形式三：紧凑式

合并操作，和形式二等价。

### 等价性

分组卷积 = C 组各自独立卷积 = C 条同构路径。

> **Inception 式多分支 和 分组卷积 是同一件事的两种写法。** ResNeXt 选分组卷积因为 GPU/CuDNN 已有高效实现。

## 五、为什么 cardinality 比加宽加深更有效？

### 5.1 实验对比

固定参数量/计算量，改变预算分配方向：

| 对比 | 设计 | 参数量 | ImageNet top-1 |
|---|---|---|---|
| ResNet-50（加宽 2×） | $C=1$，宽度 ×2 | 相近 | 较差 |
| ResNeXt-50 ($C=32$) | $C=32$，宽度不变 | 相近 | **更好** |

相同预算下，增加 $C$ 比增加宽度更有效。

### 5.2 直觉

- **加宽**：让单路卷积核更"胖"，学更复杂变换——但一个变换的容量有上限
- **加基数**：让网络同时学 $C$ 种不同变换，各路独立、可学不同特征子空间——更接近集成效果

> 类比：加宽 = 让一个人干更重的活（边际递减）；加基数 = 多请几个人各干各的（更接近集成，收益更线性）。

## 六、ResNeXt C 路聚合 vs 集成 C 个网络

### 6.1 参数共享（最关键）

ResNeXt 的 C 路**不是全程独立**：

- 首尾 1×1 卷积**共享**（所有路用同一套降维/升维参数）
- 只有中间 3×3 **分组独立**（C 组各做各的）

而 C 个独立网络从头到尾全独立。ResNeXt-50 (32×4d) 仅 25M 参数；真集成 32 个 ResNet-50 则是 800M。

### 6.2 block 级集成 vs 网络级集成

| | ResNeXt | 集成 C 个网络 |
|---|---|---|
| 集成粒度 | 每个 block 内部 C 路聚合 | 整个网络复制 C 份 |
| block 之间 | 顺序堆叠 | 各网络独立，最后投票 |
| 梯度 | loss 通过 shortcut 同时回传给 C 路 | 各网络独立反传 |

### 6.3 残差共享基座

ResNeXt 的 C 路学残差 $\mathcal{F}(x)$，共享基座 $x$（shortcut）：

$$\text{输出} = x + \sum_{i=1}^{C} \tau_i(x)$$

每路只学小残差，不从零学完整映射。

### 6.4 为什么不直接集成？

1. 参数爆炸（32 倍）
2. 训练成本（32 次完整训练）
3. 推理成本（跑 32 遍再投票）
4. 集成收益随数量递减，block 级微集成收益更均匀分布

> ResNeXt 把"集成"压缩到每个 block 内部，用分组卷积高效实现，用参数共享和残差基座大幅省成本——获得"接近集成"的效果，只有"单网络"的代价。

## 七、实验结果

| 模型 | 参数量 | GFLOPs | top-1 误差 |
|---|---|---|---|
| ResNet-50 | 25.0M | 4.1 | 22.1% |
| ResNeXt-50 (32×4d) | 25.0M | 4.2 | 21.2% |
| ResNet-101 | 44.5M | 7.8 | 21.7% |
| ResNeXt-101 (32×4d) | 44.1M | 7.8 | 20.4% |

相同参数量/计算量下，ResNeXt 一致优于 ResNet。ResNeXt-101 达 79.6% top-1，赢 ILSVRC 2016 第二名。

---

## 八、遗产

- **分组卷积**重回主流（AlexNet 早期用过后被遗弃；ResNeXt 证明它有效）
- **cardinality 成为标准设计维度**（EfficientNet、RegNet 的搜索空间）
- **SE-ResNeXt**（加 SE 模块）赢 ILSVRC 2017 冠军
- "多路同构聚合"思想影响后续大量多分支设计

## 九、与其他方法的对比

### 9.1 ResNeXt vs ResNet

| | ResNet | ResNeXt |
|---|---|---|
| 路径数 | 1 | C（典型 32） |
| 分支结构 | 无 | 全部同构 |
| 3×3 卷积 | 普通 | 分组卷积 |
| 设计维度 | 深度 + 宽度 | 深度 + 宽度 + **基数** |
| 相同参数下精度 | 较低 | 更高 |

### 9.2 ResNeXt vs Inception

| | Inception | ResNeXt |
|---|---|---|
| 分支结构 | 各异（人工设计） | 全部同构 |
| 可扩展性 | 差（换数据集要重调） | 好（只调 $C$） |
| 本质 | split-transform-merge 的特例 | split-transform-merge 的推广 |

### 9.3 与前面论文的联系

ResNeXt 复用了 ResNet v1 的 bottleneck 结构（1×1→3×3→1×1），在 3×3 处引入分组卷积。它是"ResNet 的 block + Inception 的多路 + 统一化"的融合。
