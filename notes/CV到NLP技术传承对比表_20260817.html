CV 论文 核心技术 NLP / Transformer 中的对应 继承方式 关键差异 Transformer 中的具体位置
AlexNet (2012) ReLU 激活函数 GELU / SiLU（ReLU 的平滑变体） 改造 ReLU 硬截断（max(0,x)）；GELU 用概率门控，负区间保留少量信号 Transformer FFN 中的激活函数（BERT/GPT 用 GELU，LLaMA 用 SiLU）
AlexNet (2012) Dropout 正则化 Dropout 直接继承 几乎无改动。Transformer 在 attention 权重和 FFN 中都加 Dropout Attention weights dropout + FFN dropout + residual dropout
AlexNet (2012) GPU 并行训练 GPU / TPU 并行 直接继承 AlexNet 用 2 块 GPU；Transformer 时代用 8-1024 块 GPU/TPU 数据并行 + 模型并行 + 流水线并行
VGG (2014) 堆叠相同结构加深网络 堆叠 N 个相同 Transformer Block 启发 VGG 堆叠相同 3×3 卷积块；Transformer 堆叠相同 Multi-Head Attention + FFN 块 Transformer = N × [Multi-Head Attention + FFN + 残差 + LayerNorm]
Xavier (2010) 方差分析权重初始化 $\text{Var}(W) = \frac{2}{n_{\text{in}}+n_{\text{out}}}$ Xavier / Glorot 初始化 直接继承 Transformer 原论文直接使用 Xavier 初始化（截断正态） 所有权重矩阵的初始化（Attention 的 Q/K/V/O 矩阵，FFN 的两层）
He (2015) He 初始化 $\text{Var}(W) = \frac{2}{n}$（补偿 ReLU 砍半） 类似方差分析（补偿非线性激活的方差损失） 改造 Transformer 用 Xavier 而非 He，因为 GELU 不像 ReLU 硬截断。但"补偿非线性激活方差损失"的思想被保留 部分 Transformer 变体用 He 初始化（当用 ReLU 时）
NIN (2014) 1×1 卷积（跨通道线性混合） FFN 层（跨维度线性混合） 启发 1×1 卷积在每个空间位置做跨通道线性变换 + 非线性；Transformer FFN 在每个时间步做跨维度线性变换 + 非线性。数学结构完全同构 Transformer 每层 Block 中的 FFN：Linear → GELU → Linear（先扩展再压缩）
NIN (2014) GAP 全局平均池化 Attention 池化（全局加权平均） 启发 GAP 对所有位置等权平均；Attention 对所有位置学权重后加权平均。后者是前者的可学习泛化 ViT 的 [CLS] token attention pooling；GPT 的最后输出 attention
GoogLeNet (2014) Bottleneck 结构（1×1 降维 → 3×3 → 1×1 升维） FFN 的 expand-contract 结构 改造 GoogLeNet 用 1×1 在通道维度降维→升维；Transformer FFN 用 Linear 在隐藏维度扩展→压缩。降维→升维 变成 扩展→压缩，但都是"先变换宽度再做非线性" FFN: $d_{\text{model}} \to 4 \times d_{\text{model}} \to \text{GELU} \to d_{\text{model}}$（先扩展 4 倍再压缩回去）
BN (2015) Batch Normalization（沿 batch 维度归一化） Layer Normalization（沿 feature 维度归一化） 改造 BN 沿 batch 维归一化（依赖 batch 统计）；LN 沿 feature 维归一化（与 batch 无关）。原因：NLP 序列长度可变 → batch 统计不稳定 每个 Transformer Block 中 2 个 LayerNorm（Attention 前一个，FFN 前一个）
ResNet v1 (2016) 残差连接 $x + \mathcal{F}(x)$ 残差连接（每个 Block 都有） 直接继承 几乎无改动。ResNet 的 $x + \mathcal{F}(x)$ → Transformer 的 $x + \text{Attn}(x)$ 和 $x + \text{FFN}(x)$ 每个 Transformer Block 有 2 个残差连接（Attention 后一个，FFN 后一个）
ResNet v2 (2016) Pre-activation（BN→ReLU→Conv，add 后无 ReLU） Pre-LN Transformer（LN 在 Attention 前而非后） 直接继承 ResNet v2 发现 add 后有激活会截断梯度 → Pre-activation；Transformer 同样发现 Post-LN 深层不稳 → Pre-LN。完全相同的教训 GPT-2、LLaMA、PaLM 等深层 Transformer 全部用 Pre-LN（LN 在 Attention/FFN 之前）
DenseNet (2017) Dense connectivity + 特征复用（concat） 无直接对应（标准 Transformer 不用 concat） 启发 标准 Transformer 每层独立。但 DenseNet 的"特征复用"思想在 Memory Networks、Transformer-XL 的缓存机制中有间接体现 Transformer-XL 的 memory mechanism（缓存前段 hidden states 复用）
MobileNet (2017) 深度可分离卷积（空间与通道解耦） 高效 Transformer 中的 Depthwise Conv 改造 MobileNet 解耦空间卷积和通道混合；高效 Transformer 用 depthwise conv 做局部位置编码，替代全量 attention Conformer（语音）、CoAtNet（视觉语言）中的 depthwise conv + attention 混合
ResNeXt (2017) 多路同构并行（cardinality C 路分支） Multi-Head Attention（多路并行注意力） 改造 ResNeXt 的 C 路同构分支→求和；Transformer 的 h 个注意力头→拼接。核心相同：多路并行学不同子空间。ResNeXt 用 grouped conv 高效实现，MHA 用矩阵分块高效实现 Multi-Head Attention 的 h 个头（如 8 头 = 8 路并行注意力）

三大关键改造详解

① BN → LayerNorm：从 batch 维到 feature 维

BN 的问题：NLP 中序列长度可变，一个 batch 内不同样本长度不同 → 沿 batch 维做统计会被 padding 污染。

LN 的改造：不看 batch 维，只看单个样本的 feature 维做归一化 → 与 batch 大小和序列长度无关。

BN: 对每个特征，跨所有样本归一化 → $\mu_B, \sigma_B^2 = \text{statistics over batch}$

LN: 对每个样本，跨所有特征归一化 → $\mu_l, \sigma_l^2 = \text{statistics over features}$

一句话记忆：BN 是"全班同学比平均"，LN 是"一个人各科比平均"。NLP 每个样本"科目"不同（序列长度不同），只能一个人内部比。

② ResNet v2 → Pre-LN：完全相同的教训

ResNet v2 的发现：add 后有 ReLU（post-activation）会截断梯度，深层网络训练不稳 → 把 ReLU 移到 add 之前（pre-activation）。

Transformer 的对应：Post-LN（LN 在残差之后）深层训练不稳 → Pre-LN（LN 在残差之前）深层稳定。

ResNet v2: $x \to [\text{BN} \to \text{ReLU} \to \text{Conv} \to \text{BN} \to \text{ReLU} \to \text{Conv}] \to x + \mathcal{F}(x)$

Pre-LN Transformer: $x \to [\text{LN} \to \text{Attn}] \to x + \text{Attn}(\text{LN}(x)) \to [\text{LN} \to \text{FFN}] \to x + \text{FFN}(\text{LN}(x))$

一句话记忆：add 之后不放任何非线性层——这条铁律从 ResNet v2 直接搬到了 Transformer。

③ ResNeXt → Multi-Head Attention：多路并行的两种形态

ResNeXt：C 路同构瓶颈分支 → 各自学不同变换 → 求和聚合。用 grouped convolution 高效实现。

Multi-Head Attention：h 个注意力头 → 各自学不同关注模式 → 拼接后线性变换。用矩阵分块高效实现。

数学对应：

ResNeXt: $\mathcal{F}(x) = \sum_{i=1}^{C} \tau_i(x)$（$C$ 路同构，求和聚合）

Multi-Head: $\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\, W^O$，其中 $\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$

一句话记忆：ResNeXt 是"请 32 个专才分头干再汇总"；Multi-Head 是"请 8 个专家各看一个角度再综合"。同一种思想，不同的聚合方式（求和 vs 拼接）。

传承关系全景图

直接继承（5 项）—— 几乎原样搬用

1. Dropout（AlexNet → Transformer）
2. GPU 并行（AlexNet → Transformer）
3. Xavier 初始化（Glorot → Transformer 原论文直接用）
4. 残差连接（ResNet v1 → Transformer 每个 Block）
5. Pre-activation 思想（ResNet v2 → Pre-LN Transformer）

这 5 项技术从 CV 搬到 NLP 几乎零修改，说明它们解决的是"深度网络通用问题"，不依赖具体模态。

改造继承（6 项）—— 核心不变，维度调整

1. ReLU → GELU：硬截断 → 概率门控（补偿负区间信号）
2. He 初始化思想：补偿非线性方差损失的概念保留，但 GELU 不需 2 倍补偿
3. Bottleneck → FFN expand-contract：降维→升维 变成 扩展→压缩
4. BN → LayerNorm：batch 维统计 → feature 维统计
5. Depthwise separable conv → 高效 Transformer：空间通道解耦 → 局部全局解耦
6. ResNeXt 多路 → Multi-Head Attention：grouped conv → 矩阵分块，求和→拼接

改造的原因通常是"NLP 的数据结构不同"（序列 vs 图像、可变长度 vs 固定尺寸）。

启发灵感（4 项）—— 概念迁移，非直接对应

1. VGG 堆叠相同块 → Transformer 堆叠相同 Block：架构哲学迁移
2. NIN 1×1 卷积 → FFN 层：跨通道/维度混合的数学同构
3. NIN GAP → Attention pooling：等权平均 → 可学习加权平均
4. DenseNet 特征复用 → Transformer-XL memory：显式保留历史 → 缓存前段 hidden states

启发关系最弱但有价值——它们提供了"可以这样想"的思路框架。

结论

你读的这 12 篇 CV 论文，不是孤立的 CV 技术，而是深度学习基础构件的发明史。Transformer 的三大核心组件——残差连接、归一化、多路并行——全部来自这些 CV 论文：

1. 残差连接 ← ResNet v1/v2（直接继承）
2. LayerNorm ← Batch Normalization（改造继承）
3. Multi-Head Attention ← ResNeXt 多路并行（改造继承）
4. FFN ← NIN 1×1 卷积 + GoogLeNet bottleneck（启发 + 改造）
5. Dropout ← AlexNet（直接继承）
6. 权重初始化 ← Xavier/He（直接 + 改造）

读懂这 12 篇 CV 论文，就等于读懂了 Transformer 架构设计的一半来源。
