# 精读笔记：VGG (Simonyan & Zisserman, 2014)

## 一、论文速览

- **标题**：Very Deep Convolutional Networks for Large-Scale Image Recognition
- **作者**：Karen Simonyan, Andrew Zisserman (Oxford)
- **发表**：ICLR 2015 (arXiv 2014)
- **定位**：将 CNN 深度推进到 16-19 层，统一用 $3 \times 3$ 小卷积核，确立了"小核+深层堆叠"的标准化范式。
- **关键词**：3×3 小核、深度堆叠、预训练初始化、VGG

---

## 二、痛点

AlexNet 用 $11 \times 11$、$7 \times 7$ 等大卷积核，存在两个问题：
1. 大核参数多、计算贵
2. 缺乏统一规范，不同层核大小随意
3. 深层网络仍需预训练初始化（训浅网络再迁移到深网络）

---

## 三、核心 Idea：小核级联替代大核

**核心洞察**：多个小核堆叠的感受野等于一个大核，但参数更少、非线性更多。

### 3.1 感受野等效性

两个 $3 \times 3$ 卷积（stride=1, pad=1）堆叠的感受野：

$$3 + (3-1) = 5 \quad \text{（= 一个 } 5 \times 5 \text{ 的感受野）}$$

三个 $3 \times 3$ 堆叠：

$$3 + (3-1) + (3-1) = 7 \quad \text{（= 一个 } 7 \times 7 \text{ 的感受野）}$$

### 3.2 参数对比

设通道数 $C$：

| 结构 | 感受野 | 参数量 | 非线性（ReLU） |
|------|--------|--------|---------------|
| 一个 $5 \times 5$ | $5 \times 5$ | $25C^2$ | 1 次 |
| 两个 $3 \times 3$ 堆叠 | $5 \times 5$ | $18C^2$（少 28%） | 2 次 |
| 一个 $7 \times 7$ | $7 \times 7$ | $49C^2$ | 1 次 |
| 三个 $3 \times 3$ 堆叠 | $7 \times 7$ | $27C^2$（少 45%） | 3 次 |

小核级联：相同感受野，更少参数，更多非线性→更强的判别能力。

### 3.3 为什么更多非线性是好事

每次 ReLU 都是一次非线性变换。堆叠越多层，网络能拟合的函数空间越大。两个 $3 \times 3$ + 2 次 ReLU 比一个 $5 \times 5$ + 1 次 ReLU 的表达能力更强。

## 四、网络架构

### VGG-16 结构

```
输入 224×224×3
    │
    ├─ [2× Conv 3×3, 64] → MaxPool → 112×112×64
    ├─ [2× Conv 3×3, 128] → MaxPool → 56×56×128
    ├─ [3× Conv 3×3, 256] → MaxPool → 28×28×256
    ├─ [3× Conv 3×3, 512] → MaxPool → 14×14×512
    ├─ [3× Conv 3×3, 512] → MaxPool → 7×7×512
    │
    ├─ FC 4096 (+ Dropout)
    ├─ FC 4096 (+ Dropout)
    └─ FC 1000 (softmax)
```

- 13 个卷积层 + 3 个全连接层 = 16 层（VGG-16）
- VGG-19 多 3 个卷积层（在 block 3/4/5 各多一个）
- 所有卷积核统一 $3 \times 3$，stride=1, pad=1
- 所有池化统一 $2 \times 2$，stride=2
- 通道数翻倍策略：64→128→256→512

### 4.1 预训练初始化策略

VGG 训练深层网络的方法：先训浅版（如 11 层），权重作为深版（16/19 层）的初始值，新层随机初始化。这是一种"逐层初始化"的工程手段，因为当时还没有 Xavier/He 初始化。

## 五、实验结果

| 配置 | ImageNet top-5 错误率 |
|------|----------------------|
| VGG-16 (单模型) | 7.5% |
| VGG-16 (多模型集成) | 7.3% |
| VGG-19 (集成) | 7.3% |
| AlexNet (对比) | 15.3% |

ImageNet 2014 分类亚军（冠军是 GoogLeNet 6.7%）。

### 5.1 参数分布

VGG-16 总参数 138M，其中：
- 卷积层参数：约 14.7M（仅 10.6%）
- 全连接层参数：约 123.4M（89.4%）

**绝大多数参数在 FC 层**→这启发了 NIN/GoogLeNet 用 GAP 替代 FC。

---

## 六、效果与遗产

- **$3 \times 3$ 小核成为后续所有网络的标准**
- 通道翻倍策略（池化后翻倍）被广泛采用
- 证明了深度（16-19 层）的价值
- 参数主要集中在 FC→GAP 替代 FC 成趋势
- VGG 特征（FC7 层输出）被广泛用作通用图像特征（transfer learning）

### 遗留问题

- 138M 参数太多（主要在 FC）→ NIN/GoogLeNet 用 GAP
- 仍需预训练初始化→ Xavier/He 从理论解决
- 串行堆叠导致深了仍训练困难→ BN + ResNet

## 七、与其他方法的对比

### 7.1 VGG vs AlexNet

| | AlexNet | VGG |
|---|---------|-----|
| 卷积核 | $11 \times 11$、$7 \times 7$、$5 \times 5$、$3 \times 3$ 混用 | 全部 $3 \times 3$ |
| 深度 | 8 层（5 conv + 3 fc） | 16-19 层 |
| 初始化 | 随机 | 预训练迁移 |
| 参数量 | 60M | 138M |
| top-5 | 15.3% | 7.3% |

### 7.2 VGG vs GoogLeNet

| | VGG | GoogLeNet |
|---|-----|-----------|
| 参数量 | 138M | 5M |
| 结构 | 串行 $3 \times 3$ | 多分支 Inception |
| 精度 | 7.3% | 6.7% |
| 设计哲学 | 深度+规范 | 效率+多尺度 |

GoogLeNet 用 VGG 1/28 的参数达到更高精度→1×1 降维的威力。
