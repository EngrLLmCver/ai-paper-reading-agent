1. 残差连接：ResNet → Transformer Block

CV ResNet v1 的核心：$x_{l+1} = \mathcal{F}(x_l, \{W_i\}) + x_l$。短路连接让梯度有"+1"兜底。

NLP Transformer 每个 Block 有两个残差连接：一个在 Attention 后，一个在 FFN 后。

CV ResNet BasicBlock (PyTorch)
python — ResNet v1 BasicBlock
import torch.nn as nn

class BasicBlock(nn.Module):
    def __init__(self, in_ch, out_ch, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3,
                             stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_ch)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3,
                             stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_ch)
        self.relu = nn.ReLU(inplace=True)

        # 短路连接：如果通道数变了，用 1x1 卷积对齐
        self.shortcut = nn.Sequential()
        if stride != 1 or in_ch != out_ch:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_ch, out_ch, 1, stride=stride, bias=False),
                nn.BatchNorm2d(out_ch)
            )

    def forward(self, x):
        residual = self.shortcut(x)  # 短路连接
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out = out + residual          # add: 残差核心
        out = self.relu(out)          # v1: add 后有 ReLU
        return out
NLP Transformer Block (PyTorch)
python — Transformer Encoder Block
import torch.nn as nn

class TransformerBlock(nn.Module):
    def __init__(self, d_model=512, n_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.attn = nn.MultiheadAttention(
            d_model, n_heads, dropout=dropout, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),   # expand
            nn.GELU(),                  # 激活
            nn.Linear(d_ff, d_model),   # contract
        )
        self.ln1 = nn.LayerNorm(d_model)
        self.ln2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # 残差连接 1: Attention 后
        attn_out, _ = self.attn(x, x, x)
        x = x + self.dropout(attn_out)  # add: 残差
        x = self.ln1(x)                # Post-LN

        # 残差连接 2: FFN 后
        ffn_out = self.ffn(x)
        x = x + self.dropout(ffn_out)  # add: 残差
        x = self.ln2(x)                # Post-LN
        return x

迁移要点：ResNet 的 out = out + residual 和 Transformer 的 x = x + attn_out 在数学上完全相同——都是 $x_{l+1} = x_l + \mathcal{F}(x_l)$。区别只是 $\mathcal{F}$ 的内容：CV 中 $\mathcal{F} = \text{Conv}+\text{BN}+\text{ReLU}$，NLP 中 $\mathcal{F} = \text{Attention}$ 或 $\text{FFN}$。残差连接本身是模态无关的。

2. 归一化：BatchNorm → LayerNorm

CV BN 沿 batch 维归一化：对每个通道，跨所有样本计算均值/方差。

NLP LN 沿 feature 维归一化：对每个样本，跨所有特征计算均值/方差。原因：NLP 序列长度可变，batch 统计不稳定。

CV BatchNorm 4D $(B,C,H,W)$
python — BatchNorm2d 手动实现
import torch

def batch_norm_2d(x, gamma, beta, eps=1e-5):
    # x shape: (B, C, H, W)
    # 沿 (B, H, W) 维度算统计量 → 每个通道一组 mu, sigma
    mean = x.mean(dim=(0, 2, 3), keepdim=True)
    var = x.var(dim=(0, 2, 3), keepdim=True)
    x_hat = (x - mean) / torch.sqrt(var + eps)
    return gamma * x_hat + beta

# 维度示意：
# x = (B=32, C=256, H=14, W=14)
# mean = (1, 256, 1, 1)  每个通道一个均值
# → 跨样本归一化（依赖 batch）
NLP LayerNorm 3D $(B,L,D)$
python — LayerNorm 手动实现
import torch

def layer_norm(x, gamma, beta, eps=1e-5):
    # x shape: (B, L, D)
    # 沿 D 维度算统计量 → 每个位置一组 mu, sigma
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, keepdim=True)
    x_hat = (x - mean) / torch.sqrt(var + eps)
    return gamma * x_hat + beta

# 维度示意：
# x = (B=32, L=128, D=512)
# mean = (32, 128, 1)  每个样本每个位置一个均值
# → 单样本内部归一化（不依赖 batch）
$$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y_i = \gamma \hat{x}_i + \beta$$

为什么 NLP 不用 BN：一句话——BN 是"全班同学比平均"，LN 是"一个人各科比平均"。NLP 中每个样本"科目"不同（序列长度不同），无法跨样本比，只能一个人内部比。

维度对比：BN 的统计维度 $(0,2,3)$ → LN 的统计维度 $(-1)$。唯一区别就是沿哪个轴做归一化。

3. 激活函数：ReLU → GELU

CV AlexNet 用 ReLU：$f(x) = \max(0, x)$。简单粗暴，负值完全截断。

NLP BERT/GPT 用 GELU：$f(x) = x \cdot \Phi(x)$，其中 $\Phi$ 是标准正态 CDF。负区间不是硬截断，而是概率门控。

CV ReLU
python
# ReLU: 负值完全砍掉
def relu(x):
    return torch.max(torch.tensor(0.0), x)

# x = -1 → 0   (完全截断)
# x = 0  → 0
# x = 1  → 1   (正区间导数恒=1)

# AlexNet / VGG / ResNet 全部用 ReLU
# PyTorch: nn.ReLU()
NLP GELU
python
# GELU: 负值按概率保留一点
import torch.nn.functional as F

def gelu(x):
    return F.gelu(x)
    # 等价于: x * 0.5 * (1 + erf(x / sqrt(2)))

# x = -1 → 0.041  (保留约4%)
# x = 0  → 0.5    (平滑过渡)
# x = 1  → 0.841  (略小于1)

# BERT, GPT, GPT-2 用 GELU
# LLaMA 用 SiLU = x * sigmoid(x)
# PyTorch: nn.GELU()
$$\text{ReLU: } f(x) = \max(0, x) \qquad \text{GELU: } f(x) = x \cdot \Phi(x) = \frac{x}{2}\left[1 + \text{erf}\left(\frac{x}{\sqrt{2}}\right)\right]$$

为什么 NLP 要改造：ReLU 在负区间完全截断 → 语义特征中"负值也有信息"（如"不"这个 token 的某些特征可能为负）。GELU 保留了少量负区间信号，避免信息丢失。LLaMA 进一步用 SiLU：$\text{SiLU}(x) = x \cdot \sigma(x)$，同样保留负区间。

4. 跨通道混合：1×1 卷积 → FFN 层

CV NIN 的 1×1 卷积：在每个空间位置做跨通道线性变换。

NLP Transformer 的 FFN：在每个时间步做跨维度线性变换。两者数学结构完全同构。

CV NIN 的 1×1 卷积
python — 1x1 Conv = 跨通道线性混合
# 输入: (B, C_in, H, W) — 如 (32, 256, 14, 14)
conv1x1 = nn.Conv2d(256, 128, kernel_size=1)
out = conv1x1(x)  # (32, 128, 14, 14)

# 数学等价于：
# 对每个空间位置 (i,j):
#   out[:, :, i, j] = W @ x[:, :, i, j] + b
# W: (128, 256) — 跨通道线性变换矩阵

# NIN 的 mlpconv = Conv3x3 + Conv1x1 + Conv1x1
mlpconv = nn.Sequential(
    nn.Conv2d(256, 256, 3, padding=1),  # 空间卷积
    nn.ReLU(),
    nn.Conv2d(256, 128, 1),            # 1x1: 跨通道
    nn.ReLU(),
    nn.Conv2d(128, 128, 1),            # 1x1: 跨通道
    nn.ReLU(),
)
NLP Transformer 的 FFN
python — FFN = 跨维度线性混合
# 输入: (B, L, D) — 如 (32, 128, 512)
ffn = nn.Sequential(
    nn.Linear(512, 2048),  # 扩展 4 倍
    nn.GELU(),
    nn.Linear(2048, 512),  # 压缩回去
)
out = ffn(x)  # (32, 128, 512)

# 数学等价于：
# 对每个时间步 t:
#   out[:, t, :] = W2 @ GELU(W1 @ x[:, t, :] + b1) + b2
# W1: (2048, 512), W2: (512, 2048)

# 对比 1x1 卷积：
# Conv1x1 在空间位置做跨通道 → FFN 在时间步做跨维度
# 空间位置 (i,j) ←→ 时间步 t
# 通道 C ←→ 特征维度 D
$$\text{Conv}_{1\times1}: \quad \text{out}_{i,j} = W \cdot \text{in}_{i,j} + b \qquad \text{FFN}: \quad \text{out}_t = W_2 \cdot \text{GELU}(W_1 \cdot \text{in}_t + b_1) + b_2$$

数学同构：1×1 卷积的 $W \cdot x_{i,j}$ 和 FFN 的 $W \cdot x_t$ 完全同构。把空间位置 $(i,j)$ 换成时间步 $t$，通道 $C$ 换成维度 $D$，1×1 卷积就变成了 FFN。NIN 在 2014 年发明的"每位置配一个微型大脑"思想，在 Transformer 中体现为"每时间步配一个 FFN"。

5. 多路并行：ResNeXt → Multi-Head Attention

CV ResNeXt 用 grouped convolution 实现 $C$ 路同构分支。

NLP Multi-Head Attention 用矩阵分块实现 $h$ 路并行注意力。

CV ResNeXt 的 grouped conv
python — ResNeXt Block (groups=32)
class ResNeXtBottleneck(nn.Module):
    def __init__(self, in_ch=256, out_ch=256,
                 groups=32, width_per_group=4):
        super().__init__()
        width = groups * width_per_group  # 128
        # 1x1 降维（共享入口）
        self.conv1 = nn.Conv2d(in_ch, width, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(width)
        # 3x3 分组卷积 ← 32 路并行！
        self.conv2 = nn.Conv2d(width, width, 3,
                               padding=1, groups=groups, bias=False)
        self.bn2 = nn.BatchNorm2d(width)
        # 1x1 升维（共享出口）
        self.conv3 = nn.Conv2d(width, out_ch, 1, bias=False)
        self.bn3 = nn.BatchNorm2d(out_ch)
        self.relu = nn.ReLU()

    def forward(self, x):
        residual = x
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.relu(self.bn2(self.conv2(out)))  # 32组并行
        out = self.bn3(self.conv3(out))
        return self.relu(out + residual)

# groups=32 → 32 路独立卷积
# 每路只看 4 个通道，各学各的
# 最后 1x1 升维合并
NLP Multi-Head Attention
python — Multi-Head Attention (h=8)
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, n_heads=8):
        super().__init__()
        self.h = n_heads
        self.d_k = d_model // n_heads  # 64
        # Q, K, V 投影（共享入口）
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        # 输出投影（共享出口）
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, L, D = x.shape
        # 投影后 reshape 成 h 路
        Q = self.W_q(x).view(B, L, self.h, self.d_k).transpose(1,2)
        K = self.W_k(x).view(B, L, self.h, self.d_k).transpose(1,2)
        V = self.W_v(x).view(B, L, self.h, self.d_k).transpose(1,2)
        # 8 路并行 attention
        scores = Q @ K.transpose(-2,-1) / (self.d_k ** 0.5)
        attn = F.softmax(scores, dim=-1)
        out = attn @ V  # 8头并行
        # 拼接后输出投影
        out = out.transpose(1,2).reshape(B, L, D)
        return self.W_o(out)

# n_heads=8 → 8 路独立注意力
# 每路只看 64 维子空间，各学各的
# 最后 W_o 线性投影合并
$$\text{ResNeXt: } \mathcal{F}(x) = \sum_{i=1}^{C} \tau_i(x) \qquad \text{MHA: } \text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\, W^O$$

同构对照：两者共享"首尾投影 + 中间分组"的架构：入口共享 → 中间分路 → 出口合并。ResNeXt 用 grouped conv 分路（求和聚合），MHA 用矩阵 reshape 分路（拼接聚合）。聚合方式不同（$\sum$ vs $\text{Concat}$），但思想完全一致。

6. Pre-activation：ResNet v2 → Pre-LN Transformer

CV ResNet v2：把 BN+ReLU 从 add 之后移到 之前（pre-activation），让 add 后是纯直路。

NLP Pre-LN Transformer：把 LayerNorm 从残差之后移到之前，让残差路径干净。

CV ResNet v2 Pre-activation Block
python — ResNet v2 (Pre-activation)
class PreActBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.bn1 = nn.BatchNorm2d(in_ch)
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_ch)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3, padding=1, bias=False)
        self.relu = nn.ReLU(inplace=True)

    def forward(self, x):
        # Pre-activation: BN→ReLU→Conv
        out = self.conv1(self.relu(self.bn1(x)))
        out = self.conv2(self.relu(self.bn2(out)))
        # add 后什么都没有！纯恒等
        return x + out  # 纯直路，无 ReLU

# 对比 v1:
# v1: Conv→BN→ReLU → Conv→BN → add → ReLU  (add后有ReLU)
# v2: BN→ReLU→Conv → BN→ReLU→Conv → add     (add后无ReLU)
NLP Pre-LN Transformer Block
python — Pre-LN Transformer (GPT-2/LLaMA)
class PreLNTransformerBlock(nn.Module):
    def __init__(self, d_model=512, n_heads=8,
                 d_ff=2048, dropout=0.1):
        super().__init__()
        self.ln1 = nn.LayerNorm(d_model)
        self.attn = nn.MultiheadAttention(
            d_model, n_heads, dropout=dropout, batch_first=True)
        self.ln2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Linear(d_ff, d_model),
        )
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # Pre-LN: LN 在 Attention 之前
        x_norm = self.ln1(x)
        attn_out, _ = self.attn(x_norm, x_norm, x_norm)
        x = x + self.dropout(attn_out)

        x_norm = self.ln2(x)
        ffn_out = self.ffn(x_norm)
        x = x + self.dropout(ffn_out)
        return x

# 对比 Post-LN:
# Post-LN: x = LN(x + Attn(x))  (LN在残差外层)
# Pre-LN:  x = x + Attn(LN(x))  (LN在残差内层)
$$\text{Post-LN: } x_{l+1} = \text{LN}\bigl(x_l + \mathcal{F}(x_l)\bigr) \qquad \text{Pre-LN: } x_{l+1} = x_l + \mathcal{F}\bigl(\text{LN}(x_l)\bigr)$$

完全相同的教训：ResNet v2 发现 add 后有激活函数会截断梯度 → 把激活移到 add 前。Transformer 发现 Post-LN 在深层训练不稳 → 把 LN 移到残差前。两条独立的研究路径，得到了完全相同的结论：归一化放在残差路径内部，不要放在外部。

7. 权重初始化：Xavier / He → Transformer

CV Xavier 初始化（tanh）：$\text{Var}(W) = \frac{2}{n_{\text{in}}+n_{\text{out}}}$。He 初始化（ReLU）：$\text{Var}(W) = \frac{2}{n}$。

NLP Transformer 原论文直接用 Xavier 初始化。

python — 初始化对比
# === Xavier 初始化 (Glorot 2010) ===
# 适用于 tanh / sigmoid（假设 f'(0)=1）
# PyTorch
nn.init.xavier_normal_(layer.weight)   # ~ N(0, 2/(n_in+n_out))
nn.init.xavier_uniform_(layer.weight)  # ~ U(-sqrt(6/(n_in+n_out)), sqrt(6/(n_in+n_out)))

# === He 初始化 (He 2015) ===
# 适用于 ReLU（补偿砍半的信号）
# PyTorch
nn.init.kaiming_normal_(layer.weight)   # ~ N(0, 2/n_in)
nn.init.kaiming_uniform_(layer.weight)  # ~ U(-sqrt(6/n_in), sqrt(6/n_in))

# === Transformer 初始化 (Vaswani 2017) ===
# 原论文直接用 Xavier（因为用 ReLU/GELU 但不极端深）
def init_transformer(model):
    for p in model.parameters():
        if p.dim() > 1:
            nn.init.xavier_uniform_(p)

# === 实践中的选择 ===
# ReLU + 深网络 → He 初始化
# GELU + Transformer → Xavier 初始化（足够）
# 极深 Transformer → Xavier + 残差连接 + Pre-LN（组合使用）

# 手动实现 Xavier
import math
def xavier_init(shape):
    fan_in, fan_out = shape[1], shape[0]
    std = math.sqrt(2.0 / (fan_in + fan_out))
    return torch.randn(shape) * std

# 手动实现 He
def he_init(shape):
    fan_in = shape[1]
    std = math.sqrt(2.0 / fan_in)
    return torch.randn(shape) * std
$$\text{Xavier: } \text{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}} \qquad \text{He: } \text{Var}(W) = \frac{2}{n_{\text{in}}} \qquad \text{差异: 因子 } 2 \text{（补偿 ReLU 砍半）}$$

选择规则：对称激活（tanh）用 Xavier，非对称激活（ReLU）用 He。Transformer 用 GELU（半对称）所以 Xavier 够用，但如果用 ReLU 的深层网络仍需 He。底层思想一脉相承：初始化的目标是让信号方差在每层保持稳定。

8. 完整对照：从 ResNet Block 到 Transformer Block

把以上所有迁移放在一张图里，可以看到 ResNet 和 Transformer 的架构同构性。

# ╠════════════════════════════════════════════════════════════════╣
# ║                                                                  ║
# ║  输入 x                          ←→    输入 x                   ║
# ║    │                                   │                        ║

# ║  │ BN (归一化)                     │  │ LN (归一化)              ║

# ║  │ Conv3x3 (空间变换)              │  │ MultiHeadAttn (注意力)  ║
# ║  │ BN                               │  │                        ║
# ║  │ ReLU                             │  │                        ║
# ║  │ Conv3x3                          │  │                        ║
# ║  └─┬────────┘                    ←→  └─┬────────┘               ║
# ║    │                                   │                        ║
# ║  x + out (残差连接, 纯直路)        ←→  x + out (残差连接, 纯直路) ║
# ║    │                                   │                        ║
# ║    ▼ (进入下一个Block)            ←→  ┌─┴────────┐               ║
# ║                                   │  │ LN (归一化)              ║
# ║                                   │  │ GELU (激活)              ║
# ║                                   │  │ Linear (FFN expand)     ║
# ║                                   │  │ Linear (FFN contract)    ║
# ║                                   └─┬────────┘               ║
# ║                                     │                        ║
# ║                                   x + out (第二残差连接)       ║
# ║                                     ▼ (进入下一个Block)       ║
# ║                                                                  ║
# ║  重复 N 次 (VGG式堆叠)          ←→  重复 N 次 (Transformer堆叠) ║
# ╚════════════════════════════════════════════════════════════════╝

# 组件对照表:
# ┌─────────────────┬──────────────────────┬──────────┐
# │ CV 组件         │ NLP 组件              │ 关系     │
# ├─────────────────┼──────────────────────┼──────────┤
# │ BatchNorm       │ LayerNorm             │ 改造     │
# │ ReLU            │ GELU / SiLU           │ 改造     │
# │ Conv3x3 (空间)  │ MultiHeadAttn (注意力)│ 替换     │
# │ Conv1x1 (通道)  │ Linear/FFN (维度)     │ 同构     │
# │ 残差 add        │ 残差 add              │ 直接继承 │
# │ Pre-activation  │ Pre-LN                │ 直接继承 │
# │ He/Xavier init  │ Xavier init           │ 直接继承 │
# │ Dropout         │ Dropout               │ 直接继承 │
# └─────────────────┴──────────────────────┴──────────┘

总结：Transformer Block 的架构和 ResNet v2 Block 是同构的。把 ResNet v2 的 Conv3×3 换成 Multi-Head Attention，再加一个 FFN 子层，就是 Transformer Block。归一化位置（pre）、残差连接、堆叠策略——全部来自 CV 论文。真正"原创"的只有 Attention 机制本身。
